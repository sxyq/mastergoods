# feature/agent 当前边界

当前页面已接入新版 Agent 工作台、聊天、任务/通知和草稿归档入口。本文只保留仍未完成的体验和验收边界。

## 尚未完成

- 真实 LLM 工具规划、工具结果回灌和最终正式回答闭环。
- 真机验证登录后的 Agent 主链路、历史、草稿、审计和取消。
- 只有正式回答涉及真实查询结果时才渲染表格、统计图或 KPI，普通回答不得默认显示。
- 输入法打开时顶部状态栏、输入框和消息列表不能重叠或跳动。

## 数据约束

- 过程区只展示真实后端返回的调用/状态信息。
- 图表和表格只能消费模型主动调用工具返回的当前账户数据。
- 安全审查内部执行，但不作为普通回答内容展示。
