## 一、功能用例表

| 用例 | 输入与前置 | 步骤 | 预期与验收 |

| `TEST-ADM-F01` 登录成功 | 有效超级管理员测试账号 | 登录、读取 session、刷新页面 | 返回角色/权限/范围；登录事件有时间和 IP；页面进入总览 |

| `TEST-ADM-F04` 总览空数据 | 授权范围无数据 | 打开总览、清除筛选 | 显示空状态和零值；不显示上次成功数据 |
| `TEST-ADM-F05` 用户与门店查询 | 多角色、多门店关系 | 搜索、排序、分页、打开详情 | 用户、店长、店员、门店关系正确；总数和页面一致 |
| `TEST-ADM-F06` 用户状态管理 | 超级管理员、可变更用户 | 提交状态变更、刷新详情 | 目标状态改变一次；版本、审计和会话处理正确 |
| `TEST-ADM-F07` Agent 运行列表 | 已完成/失败/进行中运行 | 按时间、用户、门店、状态和模型筛选 | 列表分页；run、conversation、actor、owner/store 字段关系清楚 |
| `TEST-ADM-F08` Agent 运行详情 | 有完整工具链的 run | 打开抽屉、加载消息/事件/草稿/上下文 | 摘要、消息、事件、草稿和检查点可追踪；查看不改变业务状态 |
| `TEST-ADM-F09` 工具事件链 | started/progress/completed/failed 事件 | 展开时间线、查看摘要 | call ID 成对；计划与实际分开；缺失序号明确提示 |
| `TEST-ADM-F10` Token 与耗时 | 精确用量、估算用量、缺失用量 | 查看运行和聚合 | 输入/输出/总量、来源、耗时、首字延迟一致；估算有标记 |
| `TEST-ADM-F11` 草稿状态 | 待确认、拒绝、确认、写入样例 | 查看草稿和业务引用 | 状态顺序正确；查看或刷新不触发写入；正式 ID 关联正确 |
| `TEST-ADM-F12` 模型和工具配置 | 合法模型 ID、注册工具 | 查看、修改、刷新运行配置 | 模型 ID/工具开关生效范围正确；密钥字段不存在；变更有版本和审计 |
| `TEST-ADM-F13` 审计查询 | 登录、读取、拒绝、配置事件 | 按动作、资源、IP、时间查询 | 审计自身查询也记录；分页和结果完整 |
| `TEST-ADM-F14` 系统状态 | 模拟服务、数据库、Provider 状态 | 打开系统页、刷新 | 状态、版本、错误类别可见；无连接字符串和秘密字段 |
| `TEST-ADM-F15` 脱敏导出 | 允许字段和范围 | 创建、查询、下载、重复下载 | 只含白名单字段；任务、过期、下载和失败均可追踪 |
| `TEST-ADM-F16` 局部失败恢复 | 让一个面板接口失败 | 打开总览、重试失败面板 | 其他面板保留；只重试失败面板；错误含 request ID 摘要 |

## 二、功能边界条件

| 类别 | 边界 |
|---|---|
| 分页 | page=0、最后一页、空页、负 page、size=1、size=200、size>200 |
| 时间 | 同一时刻、跨时区、from≥to、最大查询窗口、无时间条件 |
| ID | 合法大 ID、格式错误、不存在 ID、其他 owner 的 ID |
| 运行 | 未开始、进行中、正常完成、失败、取消、达到轮次上限 |
| 事件 | 单事件、重复事件、乱序、缺失结果、超长摘要 |
| 内容 | 无正文权限、部分脱敏、已清理正文、空消息 |
| 写操作 | 重复提交、版本冲突、幂等键冲突、审计写失败 |
| 组织 | 无门店、多个成员、停用成员、非法角色关系 |

## 三、通过条件

每个用例要同时检查 HTTP 状态、响应字段、页面状态、数据库变化、审计事件和清理结果。只收到 200 不能判定 Agent 运行成功；运行必须有正确工具事件、正式回答和终态。
