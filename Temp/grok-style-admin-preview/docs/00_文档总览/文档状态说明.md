## 一、状态定义

| 状态 | 定义 | 可否计入完成 |
|---|---|---:|
| `已完成` | 源码、测试或文档目标已经有对应证据 | 是，限于对应范围 |
| `未完成` | 尚未实现或尚未取得证据 | 否 |
| `阻塞` | 因环境、账号、设备或服务依赖无法执行 | 否 |
| `延期` | 经范围决策暂不交付 | 否，不计当前阶段缺陷 |
