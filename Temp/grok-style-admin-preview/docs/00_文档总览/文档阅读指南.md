## 二、事实与规划的区别

| 表达 | 含义 |
|---|---|
| 原型已完成 | 临时页面已实现并经过本地静态核验 |
| 正式代码已实现 | 正式 `Code/` 中有源码、测试和对应证据 |
| 规划中 | 设计已写入文档，尚未完成实现 |
| 阻塞 | 有明确环境或依赖缺口，当前无法核验 |
| 延期 | 明确不属于当前阶段交付 |

## 三、推荐评审顺序

1. 先确认两类角色和 owner/store 数据范围。
2. 再确认 Agent 运行观测所需的 actor、store、run、conversation 和 event 关联。
3. 再确认接口字段、脱敏和审计规则。
4. 再评审正式 Web/Spring Boot 目录和数据库变化。
5. 最后确认测试、部署、风险和问题解除条件。
