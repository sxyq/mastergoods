## 二、审计数据

- Agent 每次运行生成 `agent_run_audits` + `agent_run_audit_events`。
- 观测字段：`audit_id`、`trace_id`、`observability`（run id / audit id / trace id）。
- 查询：`GET /v2/agent/runs/{runId}/audit`。
- 丢损指标：`auditWriteDroppedCount` / `auditWriteFailedCount` / `auditLossy`（V17）。
