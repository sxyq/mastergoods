## 系统需求

### SR-AUTH-001 用户注册

| 字段 | 内容 |
|---|---|
| 需求编号 | SR-AUTH-001 |
| 需求名称 | 用户注册 |
| 业务目标 | 经营者通过手机号创建账户 |
| 参与角色 | 新用户 |
| 前置条件 | 无 |
| 输入 | 手机号、密码（`V2AuthDtos`） |
| 处理规则 | `AuthService` 创建用户；邀请码（`auth.invite-code` 配置）可选 |
| 输出 | 用户记录（users 表）+ session |
| 异常情况 | 手机号重复、参数校验失败（`ApiValidationTest`） |
| 权限要求 | 公开接口 |
| 涉及端 | 后端 / Android / iOS / Web |
| 对应接口 | `POST /auth/register`（`AuthController`）、`/v2/auth/*`（`V2AuthController`） |
| 对应源码 | `application/service/AuthService.java`、`domain/entity/UserEntity.java` |
| 对应测试 | `AuthServiceTest.java` |
| 验收标准 | 注册后 users 表 +1，session 可用 |
| 当前状态 | 待验证（8220 无有效 session 可复测） |

### SR-AUTH-002 用户登录与 session 创建

| 字段 | 内容 |
|---|---|
| 需求编号 | SR-AUTH-002 |
| 需求名称 | 用户登录与 session 创建 |
| 业务目标 | 用户登录后获得有效 session |
| 参与角色 | 已注册用户 |
| 前置条件 | 用户存在、密码正确 |
| 输入 | 手机号、密码 |
| 处理规则 | `AuthService` 校验凭据并创建 sessions 记录 |
| 输出 | session token |
| 异常情况 | 凭据错误 |
| 权限要求 | 公开接口 |
| 涉及端 | 后端 / Android / iOS / Web |
| 对应接口 | `POST /auth/login` |
| 对应源码 | `AuthService.java`、`SessionRepository.java` |
| 对应测试 | `AuthServiceTest.java` |
| 验收标准 | 登录后 session 可用，Token 认证通过（`TokenAuthenticationFilter`） |
| 当前状态 | 待验证（8220 sessions=0） |

### SR-AUTH-003 session 恢复

| 字段 | 内容 |
|---|---|
| 需求编号 | SR-AUTH-003 |
| 需求名称 | session 恢复 |
| 业务目标 | 客户端重启后可恢复登录态 |
| 参与角色 | 已登录用户 |
| 前置条件 | 本地保存 token（Android `core/datastore/`、iOS `AuthTokenStore.swift`、Web `app/stores/session.ts`） |
| 输入 | 本地 token |
| 处理规则 | Token 认证过滤器校验请求头中的 token |
| 输出 | 恢复登录态 |
| 异常情况 | token 过期/无效 → 403/401 |
| 权限要求 | 认证后 |
| 涉及端 | 后端 / Android / iOS / Web |
| 对应接口 | 所有受保护接口 |
| 对应源码 | `infrastructure/security/TokenService.java`、`TokenAuthenticationFilter.java` |
| 对应测试 | `testing/后端/功能测试/TEST_PLAN.md`（session 恢复场景） |
| 验收标准 | 重启后接口仍可访问 |
| 当前状态 | 待验证（8220 sessions=0） |

### SR-AUTH-004 角色与权限策略

| 字段 | 内容 |
|---|---|
| 需求编号 | SR-AUTH-004 |
| 需求名称 | 角色与权限策略 |
| 业务目标 | 成员按角色获得有限权限 |
| 参与角色 | 门店成员 |
| 前置条件 | 成员已加入门店（store_memberships） |
| 输入 | 角色（OWNER/MANAGER/SALES/PURCHASING/WAREHOUSE/FINANCE/ASSISTANT） |
| 处理规则 | `StoreAccessPolicy` 定义角色权限；`StorePermissionInterceptor` + `@RequireStorePermission("agent:view")` 等注解执行校验 |
| 输出 | 接口按权限放行或拒绝 |
| 异常情况 | 无权限 → 403 |
| 权限要求 | 门店权限注解 |
| 涉及端 | 后端 / Android / iOS / Web |
| 对应接口 | 所有 `@RequireStorePermission` 接口 |
| 对应源码 | `application/service/store/StoreAccessPolicy.java`、`infrastructure/security/RequireStorePermission.java`、`StorePermissionInterceptor.java` |
| 对应测试 | `StoreAccessPolicyTest.java`、`V2StoreControllerPermissionTest.java`、iOS `AuthPermissionTests.swift` |
| 验收标准 | 角色矩阵与后端策略一致 |
| 当前状态 | 已完成（源码与单元测试存在） |
