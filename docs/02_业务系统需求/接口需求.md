## 一、接口分层

| 层 | 位置 | 说明 |
|---|---|---|
| Controller | `api/controller/`（v1）与 `api/controller/v2/` | REST 入口，`@RestController` |
| DTO | `api/dto/` 与 `api/dto/v2/` | 请求/响应模型（record） |
| 公共 | `api/common/` | `ApiResponse`、`BusinessException`、`GlobalExceptionHandler`、`IdGenerator`、状态枚举 |
| Service | `application/service/` | 业务逻辑 |
| Repository | `infrastructure/repository/` | 数据访问 |
| Entity | `domain/entity/` | JPA 实体 |

## 二、接口约定

1. 响应统一包装：`ApiResponse<T>`（`api/common/ApiResponse.java`）。
2. 异常统一处理：`GlobalExceptionHandler` + `BusinessException`。
3. JSON 命名：`spring.jackson.property-naming-strategy=SNAKE_CASE`（application.yml），DTO 字段以 snake_case 序列化。
4. 未知字段不报错：`fail-on-unknown-properties: false`。
5. 权限：`@RequireStorePermission("agent:view"/"agent:write")` 等注解 + `StorePermissionInterceptor`。
6. SSE：`POST /v2/agent/chat/stream` 使用 `SseEmitter`，`produces = "text/event-stream"`。
