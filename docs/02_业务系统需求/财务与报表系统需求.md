## 系统需求

### SR-FIN-001 账户与转账

| 字段 | 内容 |
|---|---|
| 需求编号 | SR-FIN-001 |
| 需求名称 | 账户与转账 |
| 业务目标 | 管理资金账户并进行账户间转账 |
| 参与角色 | 财务 / 经营者 |
| 前置条件 | accounts 表存在（V10） |
| 输入 | 账户信息、转账指令 |
| 处理规则 | `V2AccountService` 维护 accounts；`V2AccountTransferService` 记录 account_transfers |
| 输出 | 账户、转账记录 |
| 异常情况 | 余额不足 |
| 权限要求 | finance 权限 |
| 涉及端 | 多端 |
| 对应接口 | `/v2/accounts/*`、`/v2/account-transfers/*` |
| 对应源码 | `application/service/v2/V2AccountService.java`、`V2AccountTransferService.java` |
| 对应测试 | `V2AccountServiceTest.java`、`V2AccountTransferServiceTest.java` |
| 验收标准 | 转账后双方余额一致 |
| 当前状态 | 已完成（源码+测试）；8220 accounts 为空 |

### SR-FIN-004 报表与 KPI

| 字段 | 内容 |
|---|---|
| 需求编号 | SR-FIN-004 |
| 需求名称 | 报表与 KPI |
| 业务目标 | 提供经营报表、KPI、表格和图表 |

| 异常情况 | 无数据、报表接口错误（历史 `sales-trend` 500 已记录） |
| 权限要求 | report/view 权限 |
| 涉及端 | 多端 / Agent |
| 对应接口 | `/v2/reports/*`（sales-summary、sales-trend 等） |
| 对应源码 | `application/service/ReportService.java`、`api/controller/v2/V2ReportController.java` |
| 对应测试 | `ReportControllerTest.java`、`ReportServiceTest.java` |
| 验收标准 | 报表数据与业务数据一致 |
