### SR-INV-001 库存台账与快照

| 字段 | 内容 |
|---|---|
| 需求编号 | SR-INV-001 |
| 需求名称 | 库存台账与快照 |
| 业务目标 | 记录每次库存变动并生成快照 |
| 参与角色 | 仓库 / 采购 |
| 前置条件 | 入库/出库/调整发生 |
| 输入 | 库存变动事件 |
| 处理规则 | `V2InventoryService` 写 inventory_ledger；生成 inventory_snapshots 与 inventory_monthly_stats |
| 输出 | 台账、快照、月度统计 |
| 异常情况 | 库存不足扣减 |
| 权限要求 | 认证后（inventory 权限） |
| 涉及端 | 多端 |
| 对应接口 | `/v2/inventory/ledger`、`/v2/inventory/snapshots`、`/v2/inventory/monthly-stats` |
| 对应源码 | `application/service/v2/V2InventoryService.java`、`infrastructure/repository/InventoryLedgerRepository.java` 等 |
| 对应测试 | `V2InventoryServiceTest.java` |
| 验收标准 | 台账与快照一致 |
| 当前状态 | 已完成（源码+测试）；8220 无库存数据 |
