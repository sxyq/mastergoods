## 系统需求

### SR-SLS-001 销售单管理

| 字段 | 内容 |
|---|---|
| 需求编号 | SR-SLS-001 |
| 需求名称 | 销售单管理 |
| 业务目标 | 创建、查询、更新销售单及明细 |
| 参与角色 | 销售 / 店长 / 经营者 |
| 前置条件 | 客户与商品存在 |
| 输入 | 客户、明细（商品、数量、价格） |
| 处理规则 | `V2SaleOrderService` 创建 sale_orders + sale_order_items，出库扣减库存 |
| 输出 | 销售单、出库记录 |
| 异常情况 | 明细为空、库存不足 |
| 权限要求 | sales 权限 |
| 涉及端 | 多端 |
| 对应接口 | `/v2/sale-orders/*` |
| 对应源码 | `application/service/v2/V2SaleOrderService.java` |
| 对应测试 | `V2SaleOrderServiceTest.java` |
| 验收标准 | 销售单 CRUD 与出库一致 |
| 当前状态 | 已完成（源码+测试）；8220 无销售数据 |
