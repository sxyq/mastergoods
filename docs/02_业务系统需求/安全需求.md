## 一、安全边界事实

1. 未鉴权访问 `https://zhj-api.sxyq27.online/` 返回 403，属于鉴权保护结果（8220 基线）。
2. 认证机制：`TokenAuthenticationFilter` + `TokenService`（session token）。
3. 授权机制：`StorePermissionInterceptor` + `@RequireStorePermission("agent:view"/"agent:write")`。
4. 数据隔离：所有业务查询按 `owner_user_id`（`CurrentOwnerService.requireCurrentOwnerUserId()`）。
5. 敏感信息：Provider API Key 只存在 8220 运行时 Secret，文档不保存、不回显（8220 基线）。
6. Agent 安全检查：`SafetyGuard` 高危关键词拦截（drop/delete/truncate）、写入频率限制（10 分钟 20 条）、否定语义识别。
7. 破坏性逆向安全测试为独立 lane：`testing/*/破坏性逆向安全测试/TEST_PLAN.md`，与常规测试分账。
