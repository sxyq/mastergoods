### SR-MEDIA-003 文本生图

| 字段 | 内容 |
|---|---|
| 需求编号 | SR-MEDIA-003 |
| 需求名称 | 文本生图 |
| 业务目标 | 文本生成图片 |
| 参与角色 | 有 agent:write 权限的成员 |
| 前置条件 | `image_generate` 已注册；`agent:write`；生图 Provider 仅从运行时占位配置读取；参考图（如有）属于当前 owner |
| 输入 | `prompt`：必填字符串，1 至 2000 个字符；`reference_asset_ids`：可选正整数数组，最多 1 个 |
| 处理规则 | Agent 调用先创建 `agent_drafts(status=active)`；手机/客户端覆盖式确认后，`AgentDraftConfirmService` 路由到 `AgentImageService.generate()`；拒绝不调用 Provider、不写正式业务表 |
| 输出 | 草稿阶段返回 `draft_id`、`draft_type=image_generate`、`status=active`；确认成功返回 `image_url`、可选 `revised_prompt`；Provider `url` 或 `b64_json` 统一为受控结果，不落敏感日志 |
| 异常情况 | Schema 拒绝、无权限、跨 owner/store、参考图不存在或非图片、Provider 未配置、HTTP 失败、空/非法响应、超时、取消；失败保留可重试草稿并记录脱敏审计 |
| 权限要求 | `agent:write` |
| 涉及端 | Android（生图弹层存在） |
| 对应接口 | `POST /v2/agent/images/generate` |
| 对应源码 | `application/service/v2/AgentImageService.java`、`infrastructure/config/AgentImageProperties.java` |
| 对应测试 | `AgentImageServiceTest.java`、`ImageGenerateToolTest.java`、`testing/Agent/功能/TEST_PLAN.md`（AG-F-DRAFT-CO-015）、`testing/Agent/契约/TEST_PLAN.md`（AG-C-SCHEMA-008/AG-C-API-021） |
| 验收标准 | 工具注册与 Schema 可追溯；确认前 Provider 调用数为 0；确认后只返回当前 owner 可见结果；拒绝/失败/取消不写正式业务表，超时后资源释放且审计可追踪 |
| 当前状态 | 工具注册与草稿代码事实 Passed；Provider、客户端、真实结果回传 Deferred |

## 对应实现

- 后端代码：`application/service/v2/V2MediaService.java`、`AgentImageService.java`、`infrastructure/storage/`

- SSE 事件：无（媒体接口非流式）
