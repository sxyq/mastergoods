## 一、数据库边界

- 数据库：PostgreSQL 15（8220 基线确认）。
- ORM：Spring Data JPA，`ddl-auto=validate`（结构由 Flyway 管理，不自动改表）。
- 迁移：Flyway `classpath:db/migration`，V1-V29。
- 当前 8220 数据库只读计数：用户 1、门店 0、session 0、Agent 会话 0、Agent 消息 0、Agent 审计 0、草稿 0（来源：8220 基线）。

## 三、owner 隔离

- `V7__owner_scope_foundation.sql`：owner 隔离基础。
- `V24__owner_scoped_query_indexes.sql`：owner-scoped 查询索引。
- 所有业务 Repository 查询按 `owner_user_id` 过滤（如 `agentConversationRepository.findAllWithMessagesByOwnerUserIdOrderByUpdatedAtDescIdDesc`）。

## 四、数据需求要点

1. 结构变更必须走 Flyway 迁移，不能依赖 Hibernate 自动建表（`ddl-auto=validate`）。
2. 迁移按版本平铺：`V1__init.sql` 至 `V29__agent_message_run_id.sql`。
3. 敏感字段（API Key、密码）不落业务表；Provider Key 只存在运行时 Secret（8220 基线）。
4. 业务主表当前为空（products、customers、suppliers、sale_orders、purchase_orders、finance_records、inventory_snapshots、inventory_ledger、accounts、payments、media_assets），测试不得建立长期种子库，只在执行时补最小夹具并记录创建/清理（`testing/README.md`）。
