## 一、可观测性需求

### SR-OBS-001 Agent 运行审计

| 字段 | 内容 |
|---|---|
| 需求编号 | SR-OBS-001 |
| 需求名称 | Agent 运行审计 |
| 业务目标 | 每次 Agent 运行可审计、可追溯 |
| 参与角色 | 系统 |
| 前置条件 | 运行开始 |
| 输入 | runId |
| 处理规则 | `RunAuditService` 创建 audit 父记录与事件序列（agent_run_audits + agent_run_audit_events）；`getRunAudit` 返回审计详情（status/mode/llm_status/plan_source/tool_count/event_count/error） |
| 输出 | 审计记录 |
| 异常情况 | 审计写失败计数（auditWriteDroppedCount / auditWriteFailedCount / auditLossy） |
| 权限要求 | `agent:view`（仅本人） |
| 涉及端 | 后端 / Agent |
| 对应接口 | `GET /v2/agent/runs/{runId}/audit` |
| 对应源码 | `application/service/v2/agent/component/RunAuditService.java` |
| 对应测试 | `testing/Agent/审计/audit_function_ledger.csv` |
| 验收标准 | SSE 事件与审计事件一致 |
| 当前状态 | 已完成（源码+测试） |
