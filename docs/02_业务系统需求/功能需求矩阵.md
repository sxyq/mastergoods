## 二、矩阵用途

1. 任何功能需求都能从本矩阵找到：需求编号 → 后端接口 → 三端实现 → Agent 工具 → 测试计划。
2. 未实现或未验证的端明确标注，不得写成"已支持"。
3. 矩阵状态与 `00_文档总览/需求追踪矩阵.md` 保持一致。
