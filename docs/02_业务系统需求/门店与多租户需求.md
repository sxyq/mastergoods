### SR-STORE-003 owner 数据隔离

| 字段 | 内容 |
|---|---|
| 需求编号 | SR-STORE-003 |
| 需求名称 | owner 数据隔离 |
| 业务目标 | 不同 owner 的数据互不可见 |
| 参与角色 | 所有用户 |
| 前置条件 | 数据表包含 owner_user_id 或按 owner 查询 |
| 输入 | 任意业务查询 |
| 处理规则 | `CurrentOwnerService.requireCurrentOwnerUserId()` 获取当前 owner；Repository 查询按 owner_user_id 过滤；Agent 工具 `query_window.owner_scope=current_owner` |
| 输出 | 仅当前 owner 的数据 |
| 异常情况 | 越权访问 → 无数据或 403 |
| 权限要求 | 认证后 |
| 涉及端 | 后端（所有端共享） |
| 对应接口 | 所有业务接口 |
| 对应源码 | `application/service/CurrentOwnerService.java`、`V7__owner_scope_foundation.sql`、`V24__owner_scoped_query_indexes.sql`、`SseStreamEmitter.queryWindowFor()` |
| 对应测试 | `CurrentOwnerServiceTest.java`、`V2SyncImportControllerTest.java`（owner 相关）、`testing/后端/功能测试/TEST_PLAN.md` |
| 验收标准 | 交叉 owner 访问无数据泄露 |
| 当前状态 | 已完成（源码+测试） |
