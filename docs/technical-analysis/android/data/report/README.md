# Android data/report 模块分析

- 对应源码目录：`master-goods-android/data/report`
- 关键源码：`ReportRepository.kt`

## 模块定位

`data/report` 在新版里不是单纯“首页卡片接口仓储”，而是 owner 私有经营聚合读模型的入口。  
重点会放在：

- 销售/采购汇总
- 财务账户报表
- 库存账本与月统计
- AI 辅助报表入口
