# Android data/finance 模块分析

- 对应源码目录：`master-goods-android/data/finance`
- 关键源码：`FinanceRepository.kt`

## 模块定位

`data/finance` 当前只覆盖轻量资金流水。  
新版里，它会成为安卓侧财务域的数据入口，逐步扩展到：

- 账户主数据
- 账户余额
- 转账
- 单据资金关联
- 找零/零钱
- 项目维度
- owner 私有财务账本
