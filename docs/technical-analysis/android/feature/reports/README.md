# Android feature/reports 模块分析

- 对应源码目录：`master-goods-android/feature/reports`
- 关键源码：
  - `ReportScreen.kt`
  - `ReportViewModel.kt`

## 模块定位

`feature/reports` 在新版里承接的是 owner 私有经营报表前台。  
重点不在图表配色，而在报表域能否覆盖：

- 销售/采购汇总
- 库存账本/月统计
- 账户与现金流
- AI 辅助分析入口

| 对象 | 状态 | 旧版情况 | 新版目标 | 当前实现 | 备注 |
