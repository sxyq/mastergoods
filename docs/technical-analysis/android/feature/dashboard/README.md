# Android feature/dashboard 模块分析

- 对应源码目录：`master-goods-android/feature/dashboard`
- 关键源码：
  - `DashboardScreen.kt`
  - `DashboardViewModel.kt`

## 模块定位

`feature/dashboard` 在新版中承担的是**owner 私有经营总览入口**。  
重点不是视觉卡片长什么样，而是首页应该能承载什么经营信息与导航分发：

- 当前 owner 的经营摘要
- 导入/同步健康状态
- 待处理业务入口
- AI 助手建议入口
