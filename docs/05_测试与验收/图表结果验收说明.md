## 一、验收范围

1. KPI 卡片（kpi_grid）渲染。
2. 表格（table / rank_list）渲染。
3. 图表（line_chart / bar_chart / pie_chart 等）渲染（仅真实数据）。
4. 草稿卡片（draft_card）渲染与操作。
5. 结果块按消息 part 顺序展示。

## 二、验收标准

| 项 | 标准 |
|---|---|
| 可见性 | draft/draft_card 恒显；图表仅在请求可视化且数据真实时显示 |
| 顺序 | 结果块按消息 part 顺序渲染 |
| 数据 | 图表数据来自真实工具结果（`hasMeaningfulChartData`） |
| 空数据 | 空图表不渲染占位 |

## 三、当前证据

- Android 结果块按消息 part 顺序渲染（8220 基线确认，本地验证）。
- 结果块证据：`docs/05_测试与验收/验收证据/ai-agent/20260609-0740-*/18-result-block-evidence.md`。

## 四、历史注意

- 默认 `evidence_card` 与默认图表已不在当前工作树产生（`testing/已知问题与解除条件.md` #13：V2AgentAiServiceTest 断言默认块不存在）。
