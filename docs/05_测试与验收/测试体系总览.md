## 四、统一执行规则

1. 每个场景必须带 `category_id`。
2. 每个函数级或场景级记录必须能回查到分类总台账。
3. 所有测试状态统一落在台账，不在聊天里代替登记。
4. 常规测试与逆向安全测试不得混账。

## 六、Stop Rules / Blocker Handling

以下情况统一记为 `Blocked`：

- 环境未起、权限未通、数据前置缺失、目标接口未启用、大模型 provider 未配置、生图 provider 未配置、真机不可复现。

禁止写成：`Passed with note`、`基本通过`、`大致可用`。
