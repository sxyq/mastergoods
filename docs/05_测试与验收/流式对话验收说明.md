## 一、验收范围

1. `POST /v2/agent/chat/stream` 事件序列正确：`run_started` →（工具事件）→ `answer_delta` → `answer_completed` → `result_block` → `run_completed`。
2. 事件 `event_type` 字段与客户端解析一致。
3. 流式回答增量连续、终态正确。
4. 取消：`run_cancelled` + audit `cancelled`。

## 二、验收标准

| 项 | 标准 |
|---|---|
| 事件顺序 | answer_completed 在 run_completed 之前 |
| 终态 | run_completed（completed/blocked）/ run_cancelled / error |
| 客户端 | Android `AgentSseClient` 解析全部事件类型 |
| 审计 | SSE 事件与 audit events 一致 |
