## 一、权限边界用例

| 用例 | 输入与前置 | 预期 |
|---|---|---|
| `TEST-ADM-S01` | 普通用户会话访问管理员 API | 401/403，不返回管理员数据 |
| `TEST-ADM-S02` | 无会话访问管理员页面和深链接 | 进入登录/拒绝状态，不加载业务数据 |
| `TEST-ADM-S03` | 审计观察员读取授权 owner/store | 只返回授权范围，读取事件完整 |
| `TEST-ADM-S04` | 审计观察员读取未授权 owner/store | 拒绝或统一不可见，不泄露存在性 |
| `TEST-ADM-S05` | 审计观察员提交用户、成员和配置变更 | 403、数据库写入为 0、拒绝审计存在 |
| `TEST-ADM-S06` | 超级管理员查询全部范围 | 结果按行带归属，分页和统计不跨错范围 |
| `TEST-ADM-S07` | 修改请求伪造角色、owner/store | 服务端以会话和授权范围为准 |
| `TEST-ADM-S08` | 猜测其他 owner 的 run/message/event ID | 不返回资源存在性或内容 |

## 二、敏感信息用例

| 用例 | 检查位置 | 预期 |
|---|---|---|
| `TEST-ADM-S09` | API JSON、异常、响应头 | 无密码、Cookie、Session Token、Provider 密钥、私钥 |
| `TEST-ADM-S10` | 浏览器本地存储、URL、DOM、埋点 | 无凭据和完整认证载荷 |
| `TEST-ADM-S11` | 运行正文和工具参数 | 无内容权限时脱敏；字段白名单生效 |
| `TEST-ADM-S12` | 导出文件 | 只有授权字段；无凭据、隐藏推理和未授权正文 |
| `TEST-ADM-S13` | 模型配置页 | 可以查看/管理模型 ID；密钥字段不存在 |
| `TEST-ADM-S14` | 错误和日志 | 无 SQL、连接串、堆栈秘密和完整请求内容 |

## 三、输入与会话测试

- 对 `query`、排序字段、时间、ID、分页和导出字段使用类型错误、超长、空白、重复和注入式输入，预期是稳定 400/422，不执行越权查询。
- 伪造代理 IP 头时，只有受信代理配置下的地址才可作为来源 IP；审计记录应保留解析结果和请求 ID。
- 重复提交配置、导出和状态变更时，验证幂等键、版本和写入次数。
- 会话过期、退出、角色撤销和账号停用后，验证旧会话不能继续读取或写入。

## 四、审计安全断言

每次登录、敏感读取、权限拒绝、配置修改、导出创建和下载都必须有管理员审计。审计事件包含操作者、角色、动作、资源、owner/store 范围、IP、request ID、结果和原因类别，但不包含凭据。

## 五、发布阻断条件

以下任一项失败，管理员后台不得进入正式发布：

1. 跨 owner/store 返回数据。
2. 审计观察员完成写操作。
3. 响应、日志或导出出现凭据。
4. 高风险写操作没有版本、幂等或审计。
5. 内容权限缺失时返回完整正文。
