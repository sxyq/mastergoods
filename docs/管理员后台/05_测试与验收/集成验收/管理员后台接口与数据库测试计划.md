## 三、数据断言范围

- 查询前后记录测试数据 ID、owner/store 和状态。
- 写操作记录变更前值、变更后值、版本和审计事件 ID。
- 草稿查询必须断言正式业务表没有新增记录。
- 导出测试记录文件字段清单、任务状态、过期时间和清理结果。
- Token 测试分别使用精确、估算和不可用三种来源，不能将估算当作精确。

## 四、查询计划

Products、customers、suppliers、finance、purchase orders、Agent runs 等列表必须检查 SQL 是否在数据库执行过滤、排序、分页和 count。没有真实 PostgreSQL 服务时，只能保存预期 SQL 和索引检查清单，结果标记 `阻塞` 或 `延期`，不能用 H2 结果替代。
