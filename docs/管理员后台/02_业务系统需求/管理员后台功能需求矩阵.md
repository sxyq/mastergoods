## 二、单功能验收矩阵

| 功能 | 成功场景 | 失败/边界场景 | 必须断言 |
|---|---|---|---|
| 登录 | 有效管理员凭据 | 无效凭据、过期会话、停用账号、重复退出 | 状态码、角色、范围、审计、无凭据泄露 |
| 总览 | 近 7 天、指定 owner/store | 空数据、非法日期、超大范围、单面板失败 | 指标总量、时间口径、局部错误、缓存标识 |
| 用户 | 搜索、分页、状态变更 | 未登录、观察员写入、跨 owner、重复提交 | 结果范围、状态前后值、审计、写库次数 |
| 门店 | 按 owner 查询、成员关系 | 不存在 store、错误 owner、移除最后店长 | 关系约束、错误映射、无半更新 |
| 运行 | 按 run 查询和排序 | 不存在 run、跨范围 run、运行仍进行中 | actor/owner/store、终态、分页、范围 |
| 消息 | 按 conversation 分页 | 消息缺失、run ID 不一致、内容无权限 | 顺序、角色、关联 ID、脱敏状态 |
| 工具链 | 查看开始/完成/失败 | 重复事件、乱序、缺少结果、参数过长 | call ID 配对、事件序列、错误状态 |
| Token | 统计输入/输出/总量 | Provider 无用量、估算、零 Token、混合模型 | 口径、估算标识、汇总正确 |
| 上下文 | 查看窗口和检查点 | 无检查点、压缩失败、窗口超限 | 上限、使用量、触发原因、事件关联 |
| 草稿 | 待确认和已写入查询 | 用户拒绝、确认失败、已删除草稿 | 状态机、正式表变化、确认人 |
| 配置 | 更新模型 ID/工具开关 | 观察员写入、非法 ID、并发版本冲突 | 服务端权限、校验、事务、审计 |
| 审计 | 按动作和时间查阅 | 无范围、超大 size、审计查询自身 | 访问事件、字段完整、敏感值缺失 |
| 导出 | 脱敏汇总导出 | 未授权字段、重复下载、任务超时 | 白名单、过期、下载审计、清理 |

## 三、接口字段追踪

| 页面字段 | 接口字段 | 数据来源 | 转换规则 |
|---|---|---|---|
| 用户总数 | `userCount` | `users` 聚合 | 按授权范围与时间口径统计 |
| 活跃门店 | `activeStoreCount` | `stores` | 只统计允许范围与有效状态 |
| 运行数 | `runCount` | `agent_run_audits` | 按终态与时间筛选 |
| 输入 Token | `inputTokens` | Provider 用量或估算字段 | 缺失时标记 `estimated=true` |
| 输出 Token | `outputTokens` | Provider 用量或估算字段 | 不把凭据字段当作 Token |
| 工具名称 | `toolName` | Agent 审计事件 | 只显示注册工具名 |
| 运行耗时 | `durationMs` | 开始/结束时间或审计字段 | 统一毫秒；未结束显示 `null` |
| 首字延迟 | `timeToFirstTokenMs` | SSE/运行事件时间 | 无事件时为 `null` 并说明原因 |
| 模型 ID | `modelId` | 运行配置快照 | 可见，密钥字段不返回 |
| 登录 IP | `sourceIp` | 管理员登录事件 | 页面可见，日志不重复写凭据 |

## 五、状态标记

| 状态 | 含义 | 页面表达 |
