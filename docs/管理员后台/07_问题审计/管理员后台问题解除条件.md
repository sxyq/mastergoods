## 二、解除评审规则

1. 单元测试通过不能单独解除权限、数据隔离或部署问题。
2. 设计文档更新不能替代源码、接口、数据库和真实环境证据。
3. 只完成原型视觉不能解除正式 API、审计和安全问题。
4. 没有 PostgreSQL 时，查询计划项保持 `阻塞` 或 `延期`。
5. 任何秘密字段出现在响应、日志或导出时，相关安全问题继续保持未完成。
