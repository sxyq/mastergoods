## 二、接口审计步骤

```mermaid
flowchart TD
    A[读取接口契约] --> B[建立角色与范围夹具]
    B --> C[执行成功/空值/异常请求]
    C --> D[核对状态码和DTO]
    D --> E[核对Repository范围和分页]
    E --> F[核对数据库变化]
    F --> G[核对管理员审计]
    G --> H[记录证据和问题编号]
```

## 三、禁止的接口行为

- 把前端传入的角色、owner 或 store 直接当作授权结论。
- 返回实体对象、原始事件 JSON、完整对话正文或未限制长度的工具结果。
- 以 HTTP 200 表示查询失败、审计失败、工具失败或草稿未确认。
- 由管理员查看接口调用 Agent、确认草稿或写入普通业务表。
- 在错误消息、日志或下载文件中返回凭据和完整认证载荷。
