# 管理员后台数据库迁移实现计划

## 文档信息

| 字段 | 内容 |
|---|---|
| 文档类型 | 数据库迁移实现计划 |
| 当前状态 | V35–V41 已创建；目标环境当前为 V40，V41 待发布 |
| 数据库基线 | 现有 Flyway 迁移 V1–V41 |
| 正式位置 | `Code/backend/src/main/resources/db/migration/` |
| 最后核对 | 2026-08-30 |

## 一、迁移前核对

1. 核对 `users`、`sessions`、`stores`、`store_memberships` 是否能表达管理员角色和观察员范围。
2. 核对现有 Agent 会话、消息、运行、事件、草稿、检查点和记忆表的实际字段与索引。
3. 核对管理员登录事件是否已有可靠来源；不能用普通用户业务表的更新时间替代登录事实。
4. 核对模型 ID、工具开关和保留策略当前存储方式，优先复用已有安全配置或配置表。
5. 核对运行审计是否能可靠得到 `actor_user_id`、`store_id`；如果不能，先补齐运行写入链再设计后台查询。

## 二、可复用现有表

| 事实 | 主要表 | 处理方式 |
|---|---|---|
| 用户和账号状态 | `users`、`sessions` | 通过服务查询，不直接暴露敏感列 |
| 门店和成员 | `stores`、`store_memberships` | 复用 owner/store 关系和角色字段 |
| Agent 会话 | `agent_conversations`、`agent_messages` | 投影读取、内容权限隔离 |
| Agent 运行 | `agent_run_audits`、`agent_run_audit_events` | 按 run/owner/时间分页读取 |
| 上下文 | `agent_context_checkpoints` | 查询窗口、版本、边界和状态 |
| 记忆 | `agent_memories` | 只读状态和范围，不展示私密字段 |
| 草稿 | `agent_drafts` | 读取草稿、确认和业务引用 |

## 三、可能新增的结构

只有现有模型无法表达时才创建新 migration：

| 结构 | 目的 | 必须包含 |
|---|---|---|
| 管理员授权范围 | 保存观察员 owner/store 授权 | 管理员、范围类型、owner/store、状态、授予者、时间、索引 |
| 管理员审计 | 保存登录、访问、拒绝、变更和导出 | admin、action、resource、IP、request、result、摘要、时间 |
| 模型/工具配置 | 保存模型 ID 和工具策略版本 | ID、工具、启用状态、范围、版本、操作者、时间 |
| 导出任务 | 支持异步脱敏导出 | 任务、范围、字段白名单、状态、过期时间、操作者 |
| 运行上下文字段 | 保存可靠 actor/store 关联 | `actor_user_id`、`store_id`、约束、索引、历史未知状态 |

新结构必须带必要的 owner/store 范围设计、索引、保留和迁移测试。不能为已有事实创建第二份无来源副本。

## 四、迁移顺序

```mermaid
flowchart LR
    A[字段与现有数据核对] --> B[管理员角色/范围结构]
    B --> C[管理员审计结构]
    C --> D[配置/导出结构]
    D --> E[actor/store运行关联]
    E --> F[Repository与接口]
    F --> G[迁移测试与查询计划]
```

每一步都要先有空库和已有数据测试。已应用 migration 不直接修改；新版本迁移必须可重复保护，失败时留下明确错误，不猜测历史 owner/store 归属。

## 五、数据安全

- migration 不保存密码、Cookie、Session Token、Provider 密钥或私钥。
- 对话正文和工具结果只在现有业务需要时保留，管理员读取由接口脱敏。
- 管理员审计保存字段摘要和结果，不保存完整请求载荷。
- 导出文件由任务策略管理，设置过期时间并记录下载。

## 六、迁移验收

| 用例 | 验收 |
|---|---|
| 空库执行 | 表、索引、约束正确 |
| 已有数据执行 | 不丢失业务数据，未知关联明确标记 |
| 重复执行 | 不产生重复结构或重复审计 |
| 范围查询 | owner/store 索引可用，越权结果为空或拒绝 |
| Agent 关联 | actor/store 有可靠来源；无来源不伪造 |
| 敏感字段 | schema、DTO、日志和导出均无秘密字段 |
