## 三、实现原则

- 优先复用正式工程已有的响应、异常、权限、分页、格式化和 API 客户端资产。
- 管理员查询使用投影 DTO，禁止直接序列化 JPA 实体和内部事件 JSON。
- 读接口与写接口分开；读接口不能触发 Agent、草稿确认或业务写入。
- 每个写操作同时校验角色、范围、版本、幂等键和审计策略。
- 新增数据库结构前先确认现有表是否已经提供同一事实，避免重复存储。
