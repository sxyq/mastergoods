# 01 状态标记规范

## 六态定义

| 状态 | 含义 | 示例 |
|---|---|---|
| 新版已做 | 已完成并可验证 | 已有实现 |
| 新版待做 | 新版目标中尚未实现 | 待开发功能 |
| 旧版存在新版未做 | 旧版有，新版缺失 | 需要补齐 |
| 新版需要去掉 | 新版明确不再保留 | 会员体系 |
| 需重构 | 现有实现能用，但结构不满足新版目标 | owner 隔离 / /v2 契约 |
| 待验证 | 已实现但需联调或验收确认 | 迁移、联调、接口对齐 |
