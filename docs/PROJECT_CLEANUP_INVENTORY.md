# 项目清理盘点表

更新时间：2026-07-27

## 使用说明

本文件是目录清理候选清单，不是删除执行记录。本轮只做盘点和分类，未删除任何文件，也未修改用户当前未提交的业务代码、测试台账或测试证据。

判断标准：

- `保留`：源码、正式配置、测试台账、验收证据或当前兼容入口。
- `可清理`：高置信度生成物、系统元数据或重复文件；删除前仍应确认没有进程正在使用。
- `需确认`：可能是历史迁移输入、设计素材、个人工具日志或外部流程依赖，不能仅凭目录名删除。
- `暂不判断`：需要逐文件内容审查，当前不纳入删除动作。

注意：`testing/.artifacts/` 体积约 715M，但其内容是已执行测试的截图、XML、logcat、接口返回和性能证据，不能按缓存处理，也不能混入“无用文件”直接删除。

## 当前结论

1. 不能把业务源码、部署配置、正式文档、测试台账、`testing/.artifacts/` 或验收证据判定为无用。
2. 高置信度可清理项主要是缓存、编译产物、Web 依赖、系统元数据和工具调用日志。
3. 迁移数据库、图像生成素材、测试证据和个人 IDE 配置必须先确认用途，再做删除或去重。
4. 本报告创建本身不改变现有文件；当前工作树中的业务改动、测试 CSV 和未跟踪证据不应通过清理提交混入。
