## 一、一致性核对

| 维度 | 结论 |
|---|---|
| 接口契约 | 三端消费同一组 `/v2/agent/*` 接口与 SSE 事件（`SseStreamEmitter` 事件清单） |
| 事件解析 | Android `AgentStreamModels` / Web `agent-stream.ts` 事件类型一致；iOS 未发现流式消费 |
| 结果块 | Android `ResultBlockRenderer` / iOS `resultBlockView` / Web `resultBlocks` 覆盖块类型一致 |
| 导航 | iOS 底部导航对齐 Android（首页/单据/档案/报表/助手）；Web 为 PC 布局 |
| 差异点 | Android 具备思考折叠/工具过程/取消；iOS 待验证；Web 部分待验证 |

## 二、不一致风险

| 风险 | 说明 |
|---|---|
| iOS SSE 缺失 | 未发现流式消费实现；iOS Agent 主流程标记待验证 |
| Web 交互未验证 | 键盘/滚动/图表渲染待验证 |
| Android 历史 RunTrace | 历史消息不恢复 RunTrace（#3），三端历史展示可能不一致 |
| 草稿入口 | Android 草稿列表无 UI 入口（#2），iOS/Web 存在但未验证 |

## 三、审计结论

- 三端共享后端契约，事件模型对齐良好（Android/Web）。
- iOS / Web 的 Agent 交互实现与行为待验证，当前不能断言三端一致。
- 一致性验证需以 8220 真实数据联调为准（当前 Blocked）。
