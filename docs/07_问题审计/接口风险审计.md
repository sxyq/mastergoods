## 一、接口风险清单

## 二、接口审计结论

1. 当前接口分层清晰（Controller → DTO → Service → Repository），统一 `ApiResponse` 与 `GlobalExceptionHandler`。
2. 权限注解覆盖 Agent 接口（`agent:view` / `agent:write`）。
3. 未发现接口层写入 API Key / Token / 密码的证据。
