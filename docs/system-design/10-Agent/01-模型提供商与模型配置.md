# 10.1 — 模型提供商与模型配置详细设计

# 1. SYSTEM_ADMIN 管理范围

SYSTEM_ADMIN 可以配置：

```text
Provider
Base URL
Credential Reference
Headers
默认 API Format
Model
Model ID
Model Enable / Disable
Context Limit
Output Limit
Tool Capability
Reasoning Effort
Variant
Input Token USD Price
Output Token USD Price
Cached Input USD Price
```

# 2. Provider → Model → Variant

```mermaid
flowchart TD
    P[Provider] --> M[Model]
    M --> V[Variant]

    P --> P1[Base URL / Credential / Headers]
    M --> M1[Model ID / API Format / Capabilities]
    V --> V1[Reasoning Effort / Settings Override]
```

覆盖优先级：

```text
Variant > Model > Provider
```

# 3. 两种 API Format

正式支持：

```text
CHAT_COMPLETIONS
RESPONSES
```

```mermaid
sequenceDiagram
    participant TASK as Agent Task
    participant RESOLVE as Model Resolver
    participant ADAPTER as Provider Adapter
    participant API as LLM Provider

    TASK->>RESOLVE: Resolve Model Snapshot
    RESOLVE-->>TASK: api_format

    alt CHAT_COMPLETIONS
        TASK->>ADAPTER: Normalized Request
        ADAPTER->>API: Chat Completions
        API-->>ADAPTER: Text / Tool Calls / Usage
        ADAPTER-->>TASK: Normalized Result
    else RESPONSES
        TASK->>ADAPTER: Normalized Request
        ADAPTER->>API: Responses
        API-->>ADAPTER: Events / Tool Calls / Usage
        ADAPTER-->>TASK: Normalized Result
    end
```

# 4. Model ID 与系统内部 Model Key 分离

```text
model_key
= 系统内部稳定标识

model_id
= 实际发送给 Provider 的模型 ID
```

管理员修改真实模型 ID 时，不需要修改业务代码。

# 5. Reasoning / Variant

统一候选可以包括：

```text
NONE
MINIMAL
LOW
MEDIUM
HIGH
XHIGH
```

但每个模型只启用真实支持的集合。

例如：

```text
fast     → LOW
standard → MEDIUM
deep     → HIGH
```

# 6. 运行配置版本化

SYSTEM_ADMIN 可以随时修改配置，但已开始 Task 不允许中途切模型配置。

```mermaid
sequenceDiagram
    actor U as User
    participant TASK as Agent Task
    participant CFG as Agent Config
    actor SA as SYSTEM_ADMIN

    U->>TASK: Start
    TASK->>CFG: Resolve Active Runtime
    CFG-->>TASK: Runtime Version 17 / Pricing Version 9

    SA->>CFG: 发布 Runtime Version 18
    CFG-->>SA: Activated

    Note over TASK: 当前 Task 继续使用 Version 17

    U->>TASK: Start New Task
    TASK->>CFG: Resolve
    CFG-->>TASK: Version 18
```

# 7. Runtime 与 Pricing 分开版本化

```mermaid
flowchart TD
    MODEL[Model]

    MODEL --> R[Runtime Config Version]
    MODEL --> P[Pricing Version]

    R --> R1[Provider / Model ID]
    R --> R2[API Format]
    R --> R3[Reasoning / Variant]
    R --> R4[Headers / Body]

    P --> P1[Input USD]
    P --> P2[Output USD]
    P --> P3[Cached Input USD]
```

# 8. Model Call Usage

每次 Model Call 至少能够追踪：

```text
task_id
call_seq
provider
model_key
model_id
runtime_config_version
variant
api_format
reasoning_effort
input_tokens
output_tokens
cached_input_tokens
pricing_version
input_usd
output_usd
cached_input_usd
total_usd
status
```

Agent Task 完成后：

```text
Σ Model Call USD Cost
= Task Total USD
```

再交给账户模块进行积分结算。

# 9. 配置发布

建议：

```text
Draft
→ Test
→ Activate
→ Rollback
```

```mermaid
sequenceDiagram
    actor SA as SYSTEM_ADMIN
    participant WEB as Admin Web
    participant CFG as Agent Config
    participant TEST as Provider Validator
    participant AUDIT as Audit

    SA->>WEB: 编辑配置
    WEB->>CFG: Save Draft

    SA->>WEB: Test
    WEB->>TEST: 测试 Provider / Model
    TEST-->>WEB: Success / Failure

    alt 成功
        SA->>WEB: Activate
        WEB->>CFG: Activate Version
        CFG->>AUDIT: Before / After
        CFG-->>WEB: 生效
    else 失败
        WEB-->>SA: 保留 Draft
    end
```
