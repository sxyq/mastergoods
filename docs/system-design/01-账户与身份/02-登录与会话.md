# 01.2 — 登录与会话详细设计

> 只讨论登录后的身份建立、移动端自动登录、Session 生命周期与失效。  
> 不在本阶段冻结 JWT / opaque token、加密算法和具体字段。

# 1. 登录需要同时验证什么

成功进入业务前至少需要确认：

```text
User 有效
账号允许登录
Role 有效
OWNER / STAFF 的 Membership 有效
Merchant 有效
```

```mermaid
sequenceDiagram
    actor U as OWNER / STAFF
    participant C as Client
    participant IAM as Identity Service
    participant DB as PostgreSQL

    U->>C: 登录
    C->>IAM: Authenticate
    IAM->>DB: 查询 User
    DB-->>IAM: User

    IAM->>DB: 查询 Membership / Merchant
    DB-->>IAM: Membership + Merchant

    IAM->>IAM: 校验账号、Membership、Merchant 状态

    alt 任一不可用
        IAM-->>C: 拒绝登录
    else 全部有效
        IAM-->>C: 登录成功 + Identity Context + New Token
    end
```

# 2. SYSTEM_ADMIN 登录

```mermaid
sequenceDiagram
    actor SA as SYSTEM_ADMIN
    participant WEB as Admin Web
    participant IAM as Identity Service
    participant DB as PostgreSQL

    SA->>WEB: 登录
    WEB->>IAM: Authenticate Admin
    IAM->>DB: 校验 SYSTEM_ADMIN User / Status
    DB-->>IAM: Platform Identity

    alt 不可用
        IAM-->>WEB: 拒绝
    else 可用
        IAM-->>WEB: 建立全局 Admin Session
    end
```

SYSTEM_ADMIN 进入某个 Merchant 时只是选择管理目标 Merchant，不获得该 Merchant Membership。

# 3. OWNER / STAFF 手工登录

```mermaid
sequenceDiagram
    actor U as OWNER / STAFF
    participant APP as Client
    participant IAM as Identity Service
    participant DB as PostgreSQL
    participant STORE as Secure Local Store

    U->>APP: 输入登录凭据
    APP->>IAM: Authenticate
    IAM->>DB: 校验 User / Membership / Merchant
    DB-->>IAM: Identity Context

    alt 校验失败
        IAM-->>APP: Login Failed
    else 校验成功
        IAM->>IAM: 签发新 Token
        Note over IAM: iOS / Android 有效期 30 天
        IAM-->>APP: Login Success + New Token
        APP->>STORE: 覆盖保存 Token
        APP-->>U: 进入系统
    end
```

# 4. iOS / Android 30 天自动登录

```mermaid
sequenceDiagram
    actor U as OWNER / STAFF
    participant APP as iOS / Android App
    participant STORE as Secure Local Store
    participant IAM as Identity Service
    participant DB as PostgreSQL

    U->>APP: 打开 App
    APP->>STORE: 读取本地 Token
    STORE-->>APP: Token / None

    alt 没有 Token
        APP-->>U: 显示登录页
    else 有 Token
        APP->>IAM: ValidateAndRefresh(Token)
        IAM->>DB: 校验 Session / User / Membership / Merchant

        alt Token 失效 / 账号停用 / Membership 停用 / Merchant 不可用
            IAM-->>APP: Session Invalid
            APP->>STORE: 删除 Token
            APP-->>U: 显示登录页
        else 有效
            IAM->>IAM: 签发新的 Token
            Note over IAM: 新有效期重新计算 30 天
            IAM-->>APP: Auto Login Success + New Token
            APP->>STORE: 覆盖旧 Token
            APP-->>U: 自动进入系统
        end
    end
```

# 5. Token 刷新原则

当前冻结：

1. 手工登录成功签发新 Token；
2. 自动登录成功也签发新 Token；
3. 客户端覆盖旧 Token；
4. 新 Token 重新获得 30 天有效期；
5. 本地 Token 必须使用系统安全存储；
6. 账号停用具有比 Token 到期时间更高的优先级。

# 6. 登出

```mermaid
sequenceDiagram
    actor U as User
    participant APP as Client
    participant IAM as Identity Service
    participant STORE as Local Secure Store

    U->>APP: 退出登录
    APP->>IAM: Logout Current Session
    IAM->>IAM: 使当前 Session 失效
    IAM-->>APP: Logout Success
    APP->>STORE: 删除当前 Token
    APP-->>U: 返回登录页
```

# 7. 多设备登录

建议默认同一个 OWNER / STAFF 可以同时保持多个独立 Session。

```mermaid
sequenceDiagram
    actor U as User
    participant PHONE as Mobile
    participant WEB as Web
    participant IAM as Identity Service

    U->>PHONE: 登录
    PHONE->>IAM: Create Session A
    IAM-->>PHONE: Session A

    U->>WEB: 登录
    WEB->>IAM: Create Session B
    IAM-->>WEB: Session B

    Note over PHONE,WEB: 两个 Session 独立存在
```

同时需要：

```text
退出当前设备
强制退出全部设备
SYSTEM_ADMIN / OWNER 停用账号时让相关 Session 全部失效
```

该建议待确认。

# 8. 密码修改后的 Session

建议：

```text
修改密码
→ 当前 Session 重新签发
→ 其他 Session 全部失效
```

此项待确认。
