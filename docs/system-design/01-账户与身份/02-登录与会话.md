# 01.2 — 登录与会话详细设计

> 状态：核心产品行为已冻结。  
> 首期 Login Identifier：PHONE / EMAIL。

---

# 1. 登录成功的完整条件

```text
Identifier 可解析
Credential 正确
User 可用
Membership 可用
Merchant 可用
Security State 允许
Risk 允许或完成 Step-up
```

```mermaid
sequenceDiagram
    actor U as OWNER / STAFF
    participant C as Client
    participant RES as Identifier Resolver
    participant IAM as Identity Service
    participant POLICY as Login Policy Pipeline
    participant RISK as Risk Engine
    participant SESSION as Session Service
    participant DB as PostgreSQL

    U->>C: PHONE / EMAIL + Password
    C->>RES: Resolve
    RES-->>C: type + normalized_value

    C->>IAM: Authenticate
    IAM->>DB: User + Membership + Merchant
    IAM->>POLICY: Evaluate Base Policies
    POLICY->>RISK: Evaluate
    RISK-->>POLICY: LOW / MEDIUM / HIGH / CRITICAL

    alt LOW
        POLICY-->>IAM: ALLOW
        IAM->>SESSION: Create Session
        SESSION-->>IAM: Token
        IAM-->>C: Login Success
    else MEDIUM
        POLICY-->>IAM: STEP_UP
        IAM-->>C: PHONE / EMAIL 二次验证
    else HIGH / CRITICAL
        POLICY-->>IAM: DENY / RECOVERY
        IAM-->>C: 临时阻断 / 恢复
    end
```

---

# 2. Identifier Resolver

Login Service 不写死 phone/email 分支。

Resolver 负责：

1. 判断类型；
2. Normalizer；
3. 返回统一结果；
4. 查询 `(type, normalized_value)` 唯一索引。

---

# 3. Merchant Context

OWNER / STAFF 都只有一个 Merchant，因此登录后不需要 Merchant Selector。

```mermaid
sequenceDiagram
    participant IAM as Identity Service
    participant DB as PostgreSQL
    participant CTX as Merchant Context

    IAM->>DB: Load Active Membership
    DB-->>IAM: Merchant + Role
    IAM->>CTX: Build Trusted Context
    CTX-->>IAM: merchant_id / role / permissions
```

客户端不能自行切到其他 merchant_id。

---

# 4. SYSTEM_ADMIN

SYSTEM_ADMIN 没有 Merchant Membership。

登录成功得到全局 Admin Context；选择 Merchant 只是管理目标。

---

# 5. iOS / Android 30 天滑动 Session

```text
手工登录成功 -> 30 天
App 下次打开 -> ValidateAndRefresh
验证成功 -> Token Rotation -> 新 30 天
```

```mermaid
sequenceDiagram
    actor U as User
    participant APP as iOS / Android
    participant STORE as Secure Store
    participant SESSION as Session Service
    participant DB as PostgreSQL

    U->>APP: 打开 App
    APP->>STORE: Read Token

    alt 无 Token
        APP-->>U: 登录页
    else 有 Token
        APP->>SESSION: ValidateAndRefresh
        SESSION->>DB: Check Session / User / Membership / Merchant

        alt 无效 / 超期
            SESSION-->>APP: Invalid
            APP->>STORE: Delete Token
            APP-->>U: 登录页
        else 有效
            SESSION->>SESSION: Rotate Token
            SESSION-->>APP: New Token / +30 days
            APP->>STORE: Replace
            APP-->>U: 自动登录
        end
    end
```

---

# 6. Token Rotation 和 Session

同一设备：

```text
Session A:
Token A1 -> A2 -> A3
```

不是每次打开 App 新建一个 Session。

---

# 7. 多设备

已冻结允许。

```mermaid
sequenceDiagram
    actor U as User
    participant PHONE as iPhone
    participant PAD as Android
    participant WEB as Web
    participant SESSION as Session Service

    U->>PHONE: Login -> Session A
    U->>PAD: Login -> Session B
    U->>WEB: Login -> Session C

    Note over PHONE,WEB: A / B / C 同时有效
```

支持退出当前设备、撤销一个 Session、强制全部退出。

---

# 8. 修改密码后的 Session

```text
当前设备 -> Rotation 后保留
其他设备 -> 全部失效
```

```mermaid
sequenceDiagram
    actor U as User
    participant APP as Current Device
    participant IAM as Identity
    participant SESSION as Session Service
    participant STORE as Secure Store

    U->>APP: Change Password
    APP->>IAM: Re-auth + Change
    IAM->>SESSION: Revoke All Other Sessions
    IAM->>SESSION: Rotate Current
    SESSION-->>APP: New Token
    APP->>STORE: Replace
```

---

# 9. SYSTEM_ADMIN 强制全部下线

使用 `security_epoch`：

```mermaid
sequenceDiagram
    actor SA as SYSTEM_ADMIN
    participant SESSION as Session Service
    participant USER as User Security
    participant AUDIT as Audit

    SA->>SESSION: RevokeAll(user)
    SESSION->>USER: security_epoch += 1
    SESSION->>AUDIT: Operator / Target / Reason
```

旧 Token 即使未过期也失效。

---

# 10. Token 最终有效条件

```text
not expired
AND session not revoked
AND token.epoch = user.epoch
AND user ACTIVE
AND membership ACTIVE
AND merchant ACTIVE
AND security_state allows business
```

不能只检查 exp。

---

# 11. Risk 对 Login

```text
LOW -> Allow
MEDIUM -> Step-up PHONE / EMAIL
HIGH -> Block + Recovery
CRITICAL -> SYSTEM_ADMIN
```

Risk 不修改经营业务数据。

---

# 12. 已冻结规则

1. PHONE / EMAIL 登录；
2. OWNER / STAFF 无 Merchant 切换；
3. 多设备同时登录；
4. iOS / Android 30 天滑动；
5. 自动登录轮换 Token；
6. 修改密码踢掉其他设备；
7. SYSTEM_ADMIN 可全部下线；
8. 安全状态优先于 Token 到期；
9. 停用账号不能靠旧 Token 继续使用。
