# 01.3 — 账号状态与商户成员关系详细设计

# 1. User 与 Membership 分离

```mermaid
flowchart TD
    USER[User]
    USER --> M1[Membership: Merchant A]
    USER --> M2[Membership: Merchant B]

    M1 --> R1[OWNER / STAFF]
    M2 --> R2[OWNER / STAFF]
```

系统底层建议允许一个 User 拥有多个 Membership。第一版产品是否开放多 Merchant 使用后续决定。

# 2. 状态层级

账号是否能工作至少需要：

```text
User Status
Membership Status
Merchant Status
```

```mermaid
sequenceDiagram
    participant IAM as Identity Service
    participant DB as PostgreSQL
    actor U as User

    U->>IAM: Request
    IAM->>DB: Load User / Membership / Merchant
    DB-->>IAM: Statuses

    alt User disabled
        IAM-->>U: Reject
    else Membership disabled
        IAM-->>U: Reject this Merchant
    else Merchant frozen / closed
        IAM-->>U: Reject Merchant business
    else All active
        IAM-->>U: Continue
    end
```

# 3. STAFF 停用

```mermaid
sequenceDiagram
    actor O as OWNER
    participant IAM as Identity Service
    participant SESSION as Session Service
    participant DB as PostgreSQL
    participant AUDIT as Audit

    O->>IAM: Disable STAFF Membership
    IAM->>DB: 修改 Membership Status
    IAM->>SESSION: 撤销该 Membership 相关 Session
    IAM->>AUDIT: 记录 OWNER / STAFF / Merchant / Reason
    IAM-->>O: 完成
```

历史业务记录不删除。

# 4. 历史操作者保留

```text
不能登录
≠
历史身份被删除
```

# 5. 最后一个 OWNER

当前建议：一个 Merchant 不允许在仍然正常营业的状态下失去最后一个有效 OWNER。

```mermaid
sequenceDiagram
    actor SA as SYSTEM_ADMIN
    participant IAM as Identity Service
    participant DB as PostgreSQL

    SA->>IAM: 停用某 OWNER
    IAM->>DB: 查询 Merchant 有效 OWNER 数量
    DB-->>IAM: 1

    alt 最后一个 OWNER 且 Merchant 仍 ACTIVE
        IAM-->>SA: 拒绝直接停用
    else 仍有其他 OWNER / Merchant 将被关闭
        IAM->>DB: 执行状态变更
        IAM-->>SA: 完成
    end
```
