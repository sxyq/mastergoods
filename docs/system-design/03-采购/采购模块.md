# 03 — 采购模块

> 状态：待分析（NOT STARTED）

本模块围绕“进货”的完整生命周期展开。后续详细分析将覆盖创建采购、商品明细、数量与进价、供应商角色、实付与欠款、付款记账、库存增加、查询、更正/撤销、采购退货与退款，以及权限、审计、一致性与异常处理。

## 模块边界

- 账户与身份：提供身份、Merchant 与权限上下文。
- 商品与库存：采购触发库存增加及后续变化。
- 往来与资金：承接供应商角色、往来余额、账户与后续付款。
- 经营分析：读取采购结果形成经营视图。
- Agent：调用同一采购业务能力，不复制采购规则。
