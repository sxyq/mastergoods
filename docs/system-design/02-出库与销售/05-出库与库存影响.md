# 05 — 出库与库存影响

> 状态：仓库经营定位已校准；库存出库完整详细设计待开始（NOT STARTED）
> 所属模块：02 出库 / 销售

## 设计目标

定义销售出库对库存产生的影响，以及库存不足、回滚和重复提交等一致性规则。

## 后续讨论范围

- 何时真正扣减库存；
- 库存检查时点；
- 库存不足；
- 是否允许负库存；
- 多商品部分库存不足；
- 出库失败后的库存回滚；
- 幂等与重复提交；
- 撤销出库后的库存恢复；
- 出库与库存之间的事务边界。

## 边界

库存盘点、手工调整和完整库存生命周期属于“04 商品与库存”；本文件只处理销售出库触发的库存变化。

---

## 2026-10-11 范围校准：出库是仓库进销存核心事实

本系统不提供外部支付接口。**库存减少与合法销售出库业务确认相关，而非等待微信支付/支付宝/银行卡付款成功事件。**
