## 2026-10-14 第二轮场景设计：销售出库库存主路径（候选方案，未冻结）

> 本节是 02 总览第 11 节的库存专项展开，属于 W-01/W-02/W-06/W-07 的**可评审方案分析**，不代表已完成 02-05 最终详细设计，尤其不代表用户已决定负库存与补录方式。

### 1. 角色与问题

OWNER 在本 Merchant 可发起正常销售出库；STAFF 必须具备授权销售能力；商户 FROZEN/CLOSED 禁止经营写入；Agent 沿用正常业务服务；SYSTEM_ADMIN 更正必须是受控的独立操作。这些继承 01/02-01 规则，不重新发散。

实际问题是：“仓库已经把什么商品、多少数量交给了别人；系统应如何清楚地记下来，并使商品库存余额和历史一致？”回答它不需要支付平台，更不意味着所有仓库减少都产生销售收入。

### 2. SaleDraft 和正式库存的分界

- 在商品行编辑阶段：商品、单位、数量可形成**出库数量候选值**与库存余额预览；不预占、不扣减正式库存，不生成正式出库流水。
- 在用户明确执行“完成销售出库”时：重新校验商品有效性、数量单位版本、权限、Merchant 状态、草稿 revision 和当前库存，以此为最终库存判断点。
- 正式成功时：一笔销售的所有有效商品行统一写出库流水，并一致更新真实账面库存；绝不因先写入第一行就留下部分扣库。
- 正式失败时：SaleDraft 仍可依最后成功保存的 revision 编辑/恢复；无已生效的正式 Sale、库存流水或同次内账副作用。
- 事务重复提交：同一业务操作请求不得再次创建库存流水或再次扣减；终态草稿不可重复消费。

### 3. 量纲与示例（多单位前提仍待 S-07）

示例：商品 A 账面 50 瓶，销售 3 箱，**假设已配置**一箱 12 瓶，候选库存减少 36 瓶、余额 14 瓶。金额依据“按箱计算的本单成交单价”，不能将销售金额除以/乘以库存数量后推断售价。

两个并发请求都看到 50 瓶，一方先确认出库 36 瓶，另一方再出库 20 瓶：后者必须基于最新库存与 W-06 策略做决策；不能两次都以初始 50 瓶为准而造成无提示超扣。可以采用已有本地数据库事务及适量行级一致性控制，不因仓库单据引入分布式协调架构。

### 4. 出库时间与补录（W-02）

需要明确区分“实际离库时间”和“系统完成登记时间”，系统时间不可由客户端自由修改。是否允许录入昨天的实际离库时间及如何进行库存时间回溯仍待用户确认；一旦允许，应保留两种时间和操作者，而不是把历史记录无痕覆盖。

只要 W-02 未确认，不能默认“录入今天即代表实物今天离库”，也不能默认补录一定可以跨日重算历史库存。若现实货物先离库、系统库存晚于实际，下一步应按 W-06 的库存差异规则而非假设支付延迟来解释。

### 5. 库存不足候选方案（W-06）

| 处理 | 性质 | 关键影响 |
|---|---|---|
| 校验不足就拒绝完成，要求先修正漏入库或盘点差异 | 候选 A | 无负库存，但真实离库补录需要额外步骤 |
| OWNER 或另行授权人确认库存差异，允许受控负库存并留下原因 | 候选 B | 方便现场，但负库存成为真实账面事实，后续须纠偏 |
| 建立“待核对、尚未正式扣库存”的特殊出库 | 仅备选 | 可能使已交付但系统未完成的记录含义混乱，须用户明确需要才进一步建模 |

当前**没有获批采用 A/B/C 任一方案**。禁止开发自行在数据库层自动放宽负库存，或悄悄把超扣截成库存归零。多商品单中任何一个商品按获批规则无法扣减时，整体交易不能只完成部分行。

### 6. 更正与退回（W-07）

错误数量/商品登记和真正退回仓库是两种不同事实，后者应有真实入库凭据；不能在原正式出库记录上直接 UPDATE quantity 让库存历史失真。按获批的冲销/更正语义关联原单、操作人和原因；涉及账面已收/欠款调整时交给 02-08、02-10 与 05 处理，不触发线上退款。

### 7. 与其他模块的唯一职责关系

- **02-01/02-02**：负责草稿、合法商品行、数量、销售单位与金额快照；
- **本 02-05**：负责“销售出库造成了多少库存变化”的判定和正式出库事件；
- **04 商品与库存**：负责商品库存台账、统一数量口径、库存盘点/调整和非销售库存事件；
- **02-03/02-04、05 往来与资金**：只根据明确的真实内账事实影响客户/账户，不驱动库存扣减；
- **02-10**：负责销售正式完成涉及的本地事务、并发、幂等和失败语义统一闭环。

### 8. 最小边界场景

| 场景 | 待确认条件下必须确保 |
|---|---|
| 重复点击“完成销售” | 不重复扣库存 |
| 3 行商品中 1 行库存不足 | 不能仅扣另外 2 行 |
| 断网造成“结果未知” | 查询同一幂等业务结果，不重复创建记录 |
| 先保存草稿、后停用商品 | 完成时重新校验并可拒绝 |
| 两个店员卖同一剩余库存 | 以后提交时的真实库存与获批负库存规则为准 |
| 实物昨日离库、今日补录 | 保留事实时间差异，何时库存生效按 W-02 决定 |
| 实物已退回，但有人将其当作错单编辑 | 不无痕抹掉原出库和入库两个事实 |
