# 07 — 出库查询、详情与历史

> 状态：待详细分析（NOT STARTED）
> 所属模块：02 出库 / 销售

## 设计目标

定义销售出库记录的查询、筛选、详情展示与历史追溯。

## 后续讨论范围

- 日期、客户、商品、操作人、金额、状态筛选；
- 列表与详情；
- 应收 / 实收 / 欠款；
- 关联后续收款；
- 更正与撤销历史；
- 库存影响；
- OWNER / STAFF / SYSTEM_ADMIN 的数据范围；
- Revision；
- 高频查询与索引。

详情应能够回答：谁、何时、给谁出了什么货、数量和成交价是多少、收了多少、欠多少、库存发生了什么变化。
