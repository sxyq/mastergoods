# 03 — 客户关联与欠款

> 状态：待详细分析（NOT STARTED）
> 所属模块：02 出库 / 销售

## 设计目标

定义销售出库与外部往来对象 CUSTOMER 角色之间的关系，以及未收金额如何形成客户欠款。

## 后续讨论范围

- 全额现结是否必须选择客户；
- 有欠款时是否必须关联客户；
- CUSTOMER 角色的现场新增 / 补充；
- 同一往来对象角色增加；
- 部分收款与全额未收；
- 客户欠款何时形成；
- 停用客户与历史出库记录；
- 无客户销售的业务边界。

## 边界

客户基础资料完整生命周期属于“05 往来与资金”；本文件只处理销售出库中的客户关联与欠款。
