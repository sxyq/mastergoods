# 02 — 销售模块

> 状态：待分析（NOT STARTED）
> 文档性质：顶层模块索引

本模块围绕“卖货”的完整生命周期展开。后续详细分析将覆盖创建销售、商品明细、数量与成交价、客户角色、实收与欠款、收款记账、库存影响、查询、更正/撤销、销售退货与退款，以及权限、审计、一致性与异常处理。

## 模块边界

- 账户与身份：提供当前用户、Merchant 与权限上下文。
- 商品与库存：提供商品资料与库存能力。
- 往来与资金：承接客户角色、往来余额、账户和后续收款。
- 经营分析：读取销售结果形成经营视图。
- Agent：调用同一销售业务能力，不复制销售规则。
