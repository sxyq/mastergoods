# 10 — 权限、风险与审计

> 状态：待详细分析（NOT STARTED）
> 所属模块：02 销售

## 设计目标

定义销售模块不同动作的授权粒度、风险等级、确认要求和审计要求。

## 后续讨论范围

- 普通创建销售；
- 修改成交价；
- 赊账；
- 改变收款账户；
- 撤销 / 作废；
- 退货 / 大额退款；
- 修改历史记录；
- OWNER / STAFF / SYSTEM_ADMIN 边界；
- Agent 继承权限；
- 高风险确认；
- Audit / Revision。

## 原则

“有销售权限”不等于可以执行所有高风险销售动作。具体权限码在讨论后冻结。
