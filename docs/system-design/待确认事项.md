## 4. 当前明确规则

- P-03 已确定：一个 Merchant 一个 OWNER；替换 OWNER 只能通过店长交接。
- 单 Merchant Membership、STAFF 自助使用 MerchantInvitation 注册的规则保持不变。
- Agent 积分归 Merchant；Task 准入后可扣成负数，只阻止下一个 Task；禁止用固定预留积分代替最终实际用量结算。
- Email 首期验证基线、P-01、P-02、P-04—P-17 的建议方案均须按上表状态等待确认；不能因已写入汇总表就视为冻结。PHONE / SMS 仅保留扩展能力，首期禁用。

## 5. 推荐确认顺序

1. 先确认 P-01、P-04—P-10，确定架构、生命周期、身份及会话基础规则。
2. 再确认 P-11、P-12、P-14、P-15 的安全验证默认值和策略边界；P-13 参数通过部署 benchmark 决定。
3. 接着确认 P-16、P-17 的 STAFF 配额与报表需求。
4. 按 Roadmap 启动 P-18—P-21 对应的后续业务 / 专题设计。
