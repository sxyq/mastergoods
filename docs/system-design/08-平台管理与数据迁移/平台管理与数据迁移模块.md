# 08 — 平台管理与数据迁移模块

> 状态：待分析（NOT STARTED）
> 文档性质：顶层模块索引

承载 SYSTEM_ADMIN 平台级管理能力，以及 Legacy 数据导出、转换、导入、重试与审计等系统级能力。

## 主要范围

- 商户与账号的平台管理。
- 平台配置和异常纠错。
- Audit / Revision 的平台查询与治理。
- Legacy DB → Exporter → Transform / Clean → New Import Package → New System。
- 导入结果、失败定位、幂等与重试。

## 关键原则

兼容旧数据，不继承旧数据库结构。SYSTEM_ADMIN 也不能绕过领域规则把系统当数据库编辑器。
