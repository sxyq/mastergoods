## 八大模块

1. **01 账户与身份**：账户、注册登录、Merchant、角色、权限、STAFF 生命周期及相关安全能力。
2. **02 出库与销售**：面向仓库进销存的一次销售出库、库存变化、销售金额、必要的人工经营账；不提供外部支付接口，不以支付成功触发库存出库。销售出库与非销售出库的分型待 W-01 确认。
3. **03 采购**：进货完整生命周期。
4. **04 商品与库存**：商品资料与库存生命周期；其中商品默认售价由 OWNER/获授权 STAFF 维护且 OWNER 可见修改历史的边界已确认，其余详细设计待开展。
5. **05 往来与资金**：外部往来对象、欠款、账户、后续收付款和其他经营收支。
6. **06 经营分析**：面向经营问题的查询、汇总与分析。
7. **07 Agent**：Provider、Conversation、Run、Context、Tool、Confirm、Result、Cost/Audit 等横切能力。
8. **08 平台管理与数据迁移**：SYSTEM_ADMIN、平台治理、Revision/Audit 与 Legacy 数据迁移。

## 2026-10-11 用户更正：进销存定位与默认售价维护

- 当前产品以**一个仓库/经营场所的进销存管理与记账**为核心：采购入库 → 商品资料/库存 → 销售出库 → 客户/供应商往来与资金 → 经营查询。
- 商品默认销售价不由系统自动决定、也不是“只有店长设置”。OWNER 可以设置，STAFF 在本商户商品维护能力范围内也可以设置；店员修改后的当前价和变更历史对 OWNER 可见。
- 商品默认售价管理属于 04 Product；02 出库与销售只读取已提交当前价和记录本单成交价快照。**设置默认商品价 ≠ 修改本次销售成交价**。
- 02-02 的 S-08 维护人和店长可见性已产品确认，剩余产品问题仍待确认；02-03 客户关联与欠款仍为下一正式子模块。
- 后续每轮交付要求：**GitHub 正式设计文档完整覆盖业务流程、Decision/Policy、并发、事务、异常、Audit、测试和待确认；对话只给关键规则、简洁 Mermaid/可视化、简要说明、当前进度与后续 Roadmap。** 完成本轮后实时更新根目录交接文档。
