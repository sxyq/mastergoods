# master-goods vNext — 八大顶层系统设计模块

> 状态：顶层模块目录已建立。01 已进入详细设计；02～08 后续逐一分析。

## 八大模块

1. **01 账户与身份**：账户、注册登录、Merchant、角色、权限、STAFF 生命周期及相关安全能力。
2. **02 销售**：卖货完整生命周期。
3. **03 采购**：进货完整生命周期。
4. **04 商品与库存**：商品资料与库存生命周期。
5. **05 往来与资金**：外部往来对象、欠款、账户、后续收付款和其他经营收支。
6. **06 经营分析**：面向经营问题的查询、汇总与分析。
7. **07 Agent**：Provider、Conversation、Run、Context、Tool、Confirm、Result、Cost/Audit 等横切能力。
8. **08 平台管理与数据迁移**：SYSTEM_ADMIN、平台治理、Revision/Audit 与 Legacy 数据迁移。
