## 三、权限差异

- Android / iOS：移动端导航包含"助手"tab；权限由后端 `agent:view` / `agent:write` 注解控制。
- iOS：`AgentAccessPolicy.swift` 控制 Agent 页面访问；`ASSISTANT` 角色展示为"AI/只读助理"。
- Web：`/agent` 路由（`routes.ts` 第 66 行）；角色访问受 `entities/auth/roles.ts` 约束。
