## 二、设计参考 vs 已实现（iOS）

`Code/frontend/ios/PAGE_MAP.md` 与 `Code/frontend/web/docs/WEB_DEVELOPMENT_ROADMAP.md` 属于设计参考与路线图；**已存在于源码**的部分以源码为准：

- iOS：`AgentChatView.swift`（对话/草稿/审计/结果块）已实现；SSE 流式、思考折叠、工具过程独立展示**未发现源码证据**（设计参考，未实现或待验证）。
- Web：`AgentPage.vue` + `agent-stream.ts`（流式）已实现；图表渲染与键盘/滚动交互待验证。

## 三、技术栈差异

| 维度 | Android | iOS | Web |
|---|---|---|---|
| UI | Jetpack Compose | SwiftUI | Vue 3 `<script setup>` |
| 网络 | OkHttp + Retrofit | URLSession（APIClient.swift） | fetch |
| SSE | 自定义 AgentSseClient | 无实现 | ReadableStream 解析 |
| 本地库 | Room | 无证据 | 无 |
| 状态管理 | ViewModel + StateFlow | ObservableObject（@StateObject） | ref/reactive |

## 四、差异影响

1. iOS / Web 的 Agent 主流程本轮未展开测试，差异矩阵中的"待验证"项不视为已实现。
2. Android 是当前 Agent 交互验证最完整的端（本地构建 + 单元测试通过）。
3. 三端共享同一套后端接口与 SSE 事件契约（`SseStreamEmitter`），行为差异主要在渲染与交互层。
