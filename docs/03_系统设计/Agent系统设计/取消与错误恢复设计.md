## 一、取消流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant S as V2AgentAiService
    participant P as Provider
    participant A as RunAuditService
    U->>S: POST /runs/{runId}/cancel
    S->>A: getActiveRun(runId) 校验 owner
    A-->>S: ActiveAgentRun
    S->>S: activeRun.cancel() 标记取消
    S->>P: longCatAnthropicClient.cancelStream(runId)
    S-->>U: run_cancelled 事件
    S->>S: persistTerminalAssistantMessage(cancelled)
    S->>A: finishRunAudit(status=cancelled)
    S-->>U: AgentRunCancelResponse(cancelled)
```

图表目的：展示取消运行的真实链路。

图中输入：runId。
图中处理：校验 owner → 标记取消 → 取消 Provider 流 → 发 `run_cancelled` → 审计 cancelled。
图中输出：`run_cancelled` 事件、取消消息、审计终态。

对应源码：`V2AgentAiService.cancelRun()`（第 498-536 行）。
对应接口：`POST /v2/agent/runs/{runId}/cancel`。
对应测试：`testing/.artifacts/2026-07-31-continuation-6/17-backend-cancel-test/11-cancel-evidence.md`。

```mermaid
flowchart TD
    A[异常发生] --> B{activeRun.cancelled?}
    B -->|是| C[取消拥有终态 不覆盖]
    B -->|否| D[finishRunAudit failed STREAM_ERROR]
    D --> E[persistTerminalAssistantMessage failed]
    E --> F[sendEvent error]
    F --> G[emitter.completeWithError]
```

图中输入：运行时异常。
