## 二、owner 隔离查询模式

Repository 查询方法统一携带 owner 维度。真实示例（`V2AgentAiService.getWorkbench`）：

```java
agentConversationRepository.findAllWithMessagesByOwnerUserIdOrderByUpdatedAtDescIdDesc(
    ownerUserId, PageRequest.of(0, 5));
agentMessageRepository.countByOwnerUserIdAndConversationId(ownerUserId, conversation.getId());
```

Agent 审计查询（`V2AgentAiService.getRunAudit`）：

```java
agentRunAuditRepository.findByRunIdAndOwnerUserId(normalizedRunId, ownerUserId)
agentRunAuditEventRepository.findAllByRunIdAndOwnerUserIdOrderBySeqAsc(normalizedRunId, ownerUserId)
```

## 三、分页

- `PageRequest.of(page, limit)`（Spring Data）。
- `PaginationUtils`（`api/common/PaginationUtils.java`）。
- Android 端分页参数：`page` / `limit`（`AgentChatViewModel.loadMoreConversations/loadMoreMessages`）。

## 四、事务

- 查询接口 `@Transactional(readOnly = true)`（如 `getWorkbench`、`listTasks`）。
- 写操作 `@Transactional`。
- Agent 编排（`chat` / `chatStream`）刻意保持大事务外执行，避免长链路回滚审计（源码注释：`Model/tool orchestration can run for tens of seconds. Keep it outside one transaction`）。
