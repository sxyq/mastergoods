## 一、消息卡片组成

| 卡片区 | Android | iOS | Web |
|---|---|---|---|
| 用户消息 | 右侧气泡 | userBubble | UiMessage.user |
| 助手消息 | 左侧卡片 | assistantBubble | UiMessage.assistant |
| 思考过程 | 默认折叠可展开 | 待验证 | PlanDelta |
| 工具过程 | 独立展示 | 待验证 | UiToolCall |
| 正式回答 | Markdown 渲染（AgentMarkdownText） | Text 渲染 | 回答区 |
| 结果块 | ResultBlockRenderer | resultBlockView | resultBlocks |

## 二、Markdown 渲染（Android）

- `feature/agent/trace/AgentMarkdownText.kt`：正式回答 Markdown 解析渲染（heading/list/ordered-list/paragraph/code/table——对应 Web `AgentPage.vue` 的 block 类型）。
- `AgentMarkdownTextParserTest.kt`：解析测试。

## 三、回答出处（Provenance）

- `AgentResponseProvenance.kt` + `AgentResponseProvenanceTest.kt`：正式回答出处（audit_id / trace_id 关联）。
