## 一、发送区规范

1. 发送区位于底部（Android）；输入框 + 发送按钮。
2. 输入为空时发送按钮禁用（iOS：`disabled(isSending || draftQuestion.nilIfBlank == nil)`）。
3. 发送中状态禁用重复发送（isSending）。
4. 支持编辑重发（`editAndResend`）、重新生成（`regenerateMessage`）——Android。
