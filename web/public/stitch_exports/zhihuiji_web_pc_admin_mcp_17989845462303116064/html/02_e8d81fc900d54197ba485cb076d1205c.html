# “智慧记 Web PC 管理端”产品需求与页面规划 ## 1. 产品需求总结 “智慧记 Web PC 管理端”是一款专为中小企业设计的全链路进销存与业务管理系统。系统旨在通过数字化手段，打通采购、销售、仓库、财务及数据库底层管理，并引入 AI 助手提升办公效率。 **核心价值点：** - **全链路覆盖：** 从基础档案到核心单据，再到财务结算与报表分析，提供一站式业务闭环。 - **智能化决策：** 集成 AI 工作台，通过自然语言交互实现任务通知、草稿生成及数据溯源（RunTrace）。 - **专业级底座：** 内置数据库管理与旧库迁移工具，支持高可用数据同步与备份。 - **权限精细化：** 支持多角色（老板、财务、仓管等）权限隔离，确保数据安全。 ## 2. 页面规模统计 - **总页面规划：** 约 68 个页面 - **首轮核心设计：** 32 个页面 ## 3. 页面分组结构与 32 个核心页面清单 ### 第一组：身份认证与系统框架 1. **登录页**：支持账号密码、验证码等多方式登录。 2. **注册页**：新租户入驻与基础企业信息录入。 3. **PC 主框架**：包含侧边导航、顶部工具栏、面包屑及多页签（Tab）容器。 ### 第二组：经营驾驶舱 4. **经营首页 Dashboard**：核心经营指标（销售、库存、现金流）可视化看板。 ### 第三组：销售业务 5. **销售单列表**：所有销售订单的分状态查询与管理中心。 6. **销售单新建/编辑**：商品选择、价格计算及订单保存。 7. **销售单详情**：查看订单详细信息、物流状态及操作日志。 8. **销售收款**：针对销售单的资金结算录入。 9. **销售退货列表**：客户退货流程的跟踪与审核。 ### 第四组：采购业务 10. **采购单列表**：向供应商下达的采购意向清单管理。 11. **采购单新建/编辑**：选择供应商及采购商品项目。 12. **采购单详情**：查看采购流程节点与关联入库情况。 13. **采购收货**：采购到货后的仓库签收与入库确认。 14. **付款单列表**：对供应商的资金支付计划与记录。 ### 第五组：基础档案 15. **商品列表**：SKU 档案库，支持条码、分类、规格管理。 16. **商品新建/编辑**：商品图片、多单位、多级价格定义。 17. **商品详情**：查看商品属性、历史单价及实时分布。 18. **客户列表**：下游买方信息、欠款额度及等级管理。 19. **客户详情**：客户全生命周期业务往来概览。 20. **供应商列表**：上游供货商档案、评价及账期管理。 21. **供应商详情**：供应商供货记录与财务往来汇总。 ### 第六组：库存与财务 22. **库存流水**：商品出入库、调拨、盘点的明细追踪。 23. **库存调整**：针对破损、丢失、溢余等非正常变动的修正。 24. **资金流水**：全公司账户的收支明细与资金流向。 25. **账户管理**：银行账户、现金账户及电子钱包的余额与状态。 ### 第七组：报表中心 26. **报表中心首页**：各类经营、财务报表的分类入口导航。 27. **销售趋势报表**：按时间轴分析销售额、利润及增长曲线。 28. **现金流/对账报表**：收支平衡分析与客户/供应商对账汇总。 ### 第八组：AI 助手与系统底座 29. **AI 工作台**：聚合任务、草稿、结果卡片的智能办公枢纽。 30. **AI 聊天页**：与 AI 助手的自然语言会话界面。 31. **数据库连接配置**：多源数据库连接、表映射及健康度检测。 32. **旧库导入/备份恢复**：历史数据平滑迁移与系统级冷热备份。
