# iOS 审计测试执行手册

## Objective

按 Swift 类型、ViewModel、API client、网络层和页面入口审查权限、输入输出、数据生命周期和跨端契约。

## Audit Items

1. API 请求字段、序列化名称、分页结构和错误模型与后端 DTO 一致。
2. owner/store 由服务端会话决定，客户端不把可变 ID 当作授权依据。
3. token、Cookie、密码和模型密钥不进入日志、截图、缓存或提交。
4. Agent 终止、取消、断线、重复事件和空数据响应不会导致错误状态覆盖已完成状态。
5. 草稿确认前不调用正式写入；拒绝确认后无正式业务数据变化。
6. ViewModel 和 Repository 复用统一模型映射、时间和金额格式化逻辑。

## Evidence

记录文件路径、符号、问题、风险、复核结论和 `result`。本手册仅为规划，不代表审计已执行。
