# iOS 破坏性逆向安全测试计划

## Objective

验证 iOS 客户端本地状态、网络请求、缓存和 Agent 入口被主动操纵后，服务端仍能守住认证、owner/store 和写入边界。

## Execution Order

1. 检查 App 产物、符号、深链、静态配置和敏感信息暴露。
2. 操纵 Keychain、UserDefaults、缓存、路由参数和本地权限状态。
3. 检查 ATS、证书校验、请求重放和响应篡改后的服务端判断。
4. 重放 Agent 历史、草稿、取消、图片载荷和确认请求。
5. 使用跨 owner/store 标识验证服务端拒绝和数据库无变化。

## Evidence

每个场景记录请求样本、响应状态、设备日志、服务端审计、数据库前后状态、清理动作和影响判断。仅依赖客户端限制的约束必须登记服务端补防项。

## Safety Boundary

仅使用授权测试账号和隔离数据；不得保存 Token、Cookie、密码、私钥或完整认证载荷。越狱、Frida、真机和生产环境验证需满足对应环境条件后再执行。
