# 后端破坏性逆向安全测试计划

## 目标

验证后端在遭遇主动攻击流量、越权重放、恶意导入、上传伪造与依赖链污染时，是否还能守住：

1. owner/multi-tenant 隔离
2. JWT/refresh/session 安全
3. 上传、导入、分页、聚合接口的资源滥用边界
4. 构建产物与依赖供应链完整性

## 证据标准

- 每个用例保留请求样本、数据库前后差异、日志片段、响应快照
- 对成功利用条目标记为阻断级问题，并写清影响资产与复现条件
- 不直接修改生产后端实现；若验证暴露必须改服务端，先暂停并回报

## 执行顺序

1. 认证与租户边界
2. CRUD/导入/上传/报表接口越权与资源滥用
3. Agent/流式接口协议攻击
4. 依赖、镜像、密钥、构建链供应链检查
