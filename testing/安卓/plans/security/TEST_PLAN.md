# 安卓破坏性逆向安全测试计划

## 目标

验证 APK 在被解包、改包、动态插桩、流量重放、客户端本地存储提取后，是否仍能保持：

1. 会话与租户边界不被绕过
2. Agent 对话、草稿、图片附件、通知链路不被伪造
3. HTTPS、签名、Root/Frida 检测和本地存储保护不过度依赖前端约束

## 证据标准

- 保留解包目录、关键 smali/Kotlin 证据、Hook 脚本、抓包结果、复现实录
- 对每个条目记录输入载荷、预期安全行为、实际结果、是否成功利用
- 一旦发现需要改后端接口权限或服务端校验，暂停实施并回到主审计流

## 执行顺序

1. 静态解包与 Manifest/Network Security 配置检查
2. 改包重签与完整性/反篡改验证
3. Frida/Objection 动态插桩
4. 本地数据库、缓存、DataStore、通知内容提取
5. Agent 图片上传、SSE、草稿确认等高价值链路重放
