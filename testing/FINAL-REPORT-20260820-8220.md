# 8220 后端与 Agent 全功能重测报告

捕获日期：2026-08-20（Asia/Shanghai）  
当前环境：`8.220.206.9`  服务器：`154.217.241.207` 已退役，仅保留历史资料。  
测试范围：后端、PostgreSQL、Provider、真实 HTTP API、Agent、SSE、取消、审计和性能；本轮不测试 Web、Android、iOS。

## 1. 测试目标与执行方法

本轮从 8220 当前环境重新建立证据，按 `Wave 0 -> Wave 1 -> Wave 2 -> Wave 3` 执行。

| Wave | 测试内容 | 本轮方式 |
|---|---|---|
| Wave 0 | 主机、容器、JAR、Flyway、Provider、ToolRegistry、数据库基线 | SSH 只读检查、容器日志、运行时配置脱敏检查、源码核对 |
| Wave 1 | 认证、门店、历史会话、业务 API、错误处理和 CRUD | 真实账号调用 8220 API，记录 HTTP/API 状态和清理结果 |
| Wave 2 | Agent 读工具、写工具、正式回答、图表和草稿 | 真实 `/v2/agent/chat` 请求，检查 Function Calling、工具结果、回答、数据库变化和清理 |
| Wave 3 | SSE、取消、审计、原生续轮和性能 | 保存 Provider/SSE 原文，检查事件顺序、终态、并发和延迟分布 |

每个 Agent case 都检查目标工具、工具是否完成、正式回答是否存在、业务表前后差异、owner 范围和清理状态。HTTP 200 只代表传输请求成功，不单独作为 Agent 通过条件。

## 4. 后端 API 结果

真实 API 只读探针共 75 个 case：

- 66 个有效接口返回 HTTP 200。
- 1 个无效 Token 返回 HTTP 403。
- 8 个不存在资源或无效审计资源返回 HTTP 422。
- `/v2/payments` 返回 HTTP 404，源码中也未找到独立 Payments Controller；现有付款能力通过销售单付款、付款单和资金关联接口提供，该路径是否属于当前契约需要单独确认。

真实 CRUD 共 32 个请求，覆盖分类、单位、价格等级、客户、供应商、商品、商品供应商关系和资金账户；创建、读取、更新、列表与清理请求均完成，8 个临时对象最终删除。

其他接口证据：销售单 PDF 导出返回 `application/pdf`，大小 1841 字节；媒体上传、元数据读取、绑定、内容读取、解绑和删除均返回预期 HTTP 状态，最终媒体记录、绑定和存储文件数为 0。

## 6. 历史会话与 owner 范围

以下接口本轮均可访问：`auth/users/me`、`stores/current`、`stores/current/members`、`workbench`、`drafts`、`tasks`、`notifications`、`run-traces`。

发现两个当前契约问题：

1. `/v2/agent/conversations` 返回空列表，但 `/v2/agent/workbench` 返回已有会话，`/run-traces` 也能读到两条运行记录。
2. 带显式 `conversation_id` 的 `/v2/agent/chat` 请求返回 HTTP 400；不带该字段时真实 Agent 请求可以完成。

这两项直接影响 Android 历史 Chat 恢复和连续对话，当前发布门禁保持未通过。

## 7. SSE、取消、审计与性能

- 10 路并发 SSE：10/10 HTTP 200，10/10 `run_started`，10/10 `run_completed`，10/10 正式回答，10/10 临时会话删除成功。
- SSE 延迟：P50 17.574 秒，P95 19.143 秒，最大 20.967 秒。
- 取消：收到 `run_started -> run_cancelled`，取消 HTTP 200，审计终态为 `cancelled`，连接关闭。
- 30 轮非流式：30/30 HTTP 200，30/30 正式回答；P50 18.245 秒，P95 25.414 秒，最大 47.563 秒。
- 当前没有明确性能阈值，因此这些数字只作为实测分布，不宣称性能达标。

## 8. 其他发现

- `/v2/payments` 独立列表接口缺失，需要确认是否为文档、客户端或后端契约问题。
- 分类和单位接口可以接受较长名称，但商品创建在相同输入下出现 HTTP 500，输入校验与数据库字段长度约束不一致。
- 媒体删除接口返回成功后，本轮曾发现测试图片文件残留；已按精确路径清理，当前数据库记录、绑定和 `/data/media` 文件数均为 0。媒体删除链路应继续补充自动清理断言。
- 多模态、生图、图片输入和图片结果展示仍为 `Deferred`，等待 Provider 和设计资料。
- Android 真机因 ADB 未连接仍为 `Blocked`；本轮目标限定为后端与 Agent，未把 Android 结果计入当前后端结论。
