# Web 破坏性逆向安全测试计划

## 目标

验证 Web 端在被反编译 bundle、篡改本地状态、绕过页面守卫、重放 SSE/上传请求后，是否仍不能突破服务端边界。

## 证据标准

- 保留 bundle/source-map 分析结果、浏览器控制台操作、拦截/重放请求、页面录屏
- 任何仅靠前端禁用态或页面守卫维持的约束，都必须记为服务端风险

## 执行顺序

1. 前端 bundle/source map/静态配置暴露检查
2. localStorage/sessionStorage/路由参数篡改
3. Agent 页面 SSE 与侧栏请求重放
4. 图片上传、表单提交、按钮禁用绕过
