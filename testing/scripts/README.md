## Agent 工具选择评估

`run_server_agent_all_tools.py` 的 `expected_tool_sets` 表示某个问题允许的
完整工具名称集合。模型可以自主选择单个工具或多个相关工具；评估器只在实际
调用集合精确匹配其中一个允许集合时通过。允许集合不能用一个“全集”代替，避免
把可选辅助工具误判成必选工具。

评估规则：

- 允许的相关辅助工具必须在该 case 的单独集合中声明；例如客户创建前查询客户分组。
- 缺少该集合中的工具、调用未声明的工具，或出现额外工具，保持 `Failed`。
- 同一工具重复调用不会因集合去重而自动获得通过；需要结合调用序列和工具事件审查。
- 真实历史 JSON 证据保持不可变。修改评估契约后，必须用原始证据重新运行本地判定检查。

python3 -m unittest testing/scripts/test_run_server_agent_all_tools.py
