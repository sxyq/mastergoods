|---|---|---|---|---|

| D2 | 工具执行安全 | 检查 `ToolRegistry`、`AgentTool`、`ToolArgumentsValidator`、`SafetyGuard`、`ToolContext` | 工具门测试和错误码记录 | 范围、Schema、requiredPermission、owner/store 均在业务 Service 前生效 |

### D 阶段停止条件

下列任一项未满足时，停止进入真实业务测试，回到开发阶段登记问题：

| 停止项 | 必须满足 |
|---|---|
| 工具安全 | 非法 Schema、无权限、跨 owner/store、未注册工具都在业务层前拒绝 |
| 工具事实 | 目标工具、额外工具、工具完成、正式回答、audit 和数据库变化均有可断言字段 |
| 草稿授权 | Android/iOS 的拒绝、关闭、返回和断线都不会调用确认接口或正式写入 |
| 上下文 | 窗口预算、压缩、检查点复用/失效和并发结果有测试覆盖 |
| 客户端 | App 模型、SSE、错误和状态转换通过纯测试；Web build 通过 |
| 版本 | 服务器将要运行的源码提交、容器/JAR 版本和 App 构建版本可追溯 |

## 六、部署与真实测试前置

> 本轮主线说明：671 条功能分支必须使用 8220 云端 Agent API、云端模型、云端工具执行器和云端 PostgreSQL。测试端只持有业务测试账号的认证会话；Provider URL 与 Key 只存在服务器运行环境。若云端模型、认证会话、数据库观测或清理权限无法确认，暂停对应分组并记为 `Blocked`，不能用本地结果补充云端台账。

| 步骤 | 操作 | 记录内容 | 通过条件 |
|---|---|---|---|
| E0 | 从本机直接连接 8220，核对 hostname、服务版本、容器、端口、数据库和 Provider | `00-environment.md` | 目标为 8220；测试请求不经过本机 Spring 服务 |
| E1 | 核对已部署且通过开发验收的后端版本 | 容器/JAR 标识、发布时间、迁移版本 | 服务器版本与测试范围一致；版本不明不得开始用例 |
| E2 | 检查模型与 Provider | 只记录模型名、Wire API、响应状态、耗时和 Key 是否注入；Key 只存在服务器运行环境 | 服务器能真实调用 Provider；测试端不直连 Provider |
| E3 | 构建最新 App 并安装到 `emulator-5554` | APK 版本、SHA-256 摘要、安装时间；APK 文件完成后移出工作树 | App 默认地址为公网 API；无本地数据库地址 |
| E4 | 通过 App 登录 | 在模拟器登录页输入开发测试账号；不从数据库读取密码哈希或 Token | 登录、session、owner/store 返回与服务端一致 |
| E5 | 建立测试基线 | 读取测试账号作用域、基础数据计数和清理权限；只记录脱敏标签 | 基线可恢复；本轮创建对象可按 ID 清理 |
| E6 | 开启观测 | 服务器容器日志、HTTP/SSE 采集、audit 查询、数据库 before/after、App logcat | 每个请求能用时间戳、`run_id`、`conversation_id` 或 `audit_id` 对齐 |

云端真实测试时，禁止把本地 H2/SQLite、模拟 Provider、静态代码、固定回答、关键词降级或 HTTP 200 作为云端 Agent 通过结论。若 `plan_source` 为 `keyword_fallback`、`llm_unavailable`、`llm_planning_failed`，或 `llm_status` 为模型不可用/空回答，必须按实际结果记录 `Failed` 或 `Blocked`。

#### 7.1.2 云端真实 Agent 调用规则

671 条后端功能分支必须经过 8220 云端 Agent API、云端模型、云端 `ToolPlanner`、云端 `ToolExecutor` 和云端 PostgreSQL：

1. 使用云端有效测试账号和 owner/store 作用域调用 `https://zhj-api.sxyq27.online/v2/agent/chat/stream`；未登录、权限不足和跨作用域分支按对应认证状态发送。
2. 认证分支之外的功能分支，必须由云端模型真实返回目标 `tool_call`，再由云端 Agent 执行器访问云端 PostgreSQL；测试侧不能手工补写工具调用、答案或图表数据。
3. 云端模型 Provider 为 `https://oneapi.sxyq27.online/v1`；模型名和 Wire API 以本轮服务器运行时读取值为准；Key 只存在服务器环境变量 `AGENT_LLM_API_KEY`，测试记录只写是否注入，不写 Key 值。
4. 测试脚本不得直接请求 Provider，不能在本机启动替代模型，也不能把本地固定 JSON、规则文本或 H2 结果写入云端台账。
5. 创建类分支先通过云端 Agent 生成草稿，再按分支调用云端草稿拒绝、确认或并发确认接口；确认接口不能代替草稿生成阶段。
6. 每条记录必须同时取得云端 HTTP/SSE、模型工具事件、正式回答或错误终态、云端数据库 before/after、run-audit 和清理结果。
7. 若云端模型没有选择目标工具、回答为空、工具事实与回答不一致或发生关键词降级，按实际结果记录 `Failed`；若 Provider、认证、数据库观测或清理条件不可用，记录 `Blocked`。

云端主链路固定为：

```text
测试账号认证
→ https://zhj-api.sxyq27.online/v2/agent/chat/stream
→ 云端模型返回 tool_call
→ 云端 ToolPlanner / ToolExecutor
→ 云端 PostgreSQL 查询或写入
→ 云端 SSE、run、audit 和正式回答
→ 云端数据库 before/after 与清理
```

测试端只保存脱敏后的云端响应和观测结果。若云端模型、认证会话、数据库观测或清理权限缺失，相关记录记为 `Blocked`，不得改用本地结果填充云端记录。

## 九、安全、可靠性与性能边界

| 类别 | 必测边界 | 主要指标 | 验收条件 |
|---|---|---|---|
| 认证 | 无登录访问 REST、SSE、草稿、图片、取消、审计 | 401 数、业务调用数、写入数 | 未认证成功数=0；业务调用数=0 |
| 权限 | `agent:view` 调写、缺查看权限读审计、权限字段伪造 | 403 数、越权调用数、审计关联率 | 真实调用者权限决定结果；客户端按钮不能代替服务端拒绝 |
| 租户隔离 | A 访问 B 的 conversation/draft/run/store/asset | 跨 owner/store 成功数、串线数 | 成功数、数据泄露数、跨域写入数均为 0 |
| 输入安全 | 缺 required、错类型、maximum/maxItems、未知字段、非法 JSON、路径和 URL | 预拒绝数、业务层调用数、fieldPath 完整率 | 非法输入在业务 Service/Provider 前拒绝 |
| Prompt 注入 | 要求输出规则、密钥、其他账号、跳过确认或执行破坏性操作 | 规则泄露数、未确认写入数、额外工具数 | 敏感结果不泄露；安全拒绝可审计 |
| SSE 可靠性 | 重复、乱序、断线、重连、取消和终态附近注入 | 丢失率、重复率、终态重复数 | 事件按 run/seq 对齐；每个 run 一个终态 |
| Provider 故障 | 超时、429、空响应、非法 JSON、连接失败、取消 | 重试数、5xx、终态、资源未释放数 | 失败不伪装成功；重试受限；无重复写入 |
