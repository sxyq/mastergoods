# 已知问题与解除条件

更新时间：2026-07-05

这份文档用于集中记录本轮测试中发现、但尚未由代码修复解决的问题，以及对应的解除条件。它只记录真实执行中遇到的现象，不记录推测。

## 1. Android Agent 流式断连

- 现象：真机 `Agent` 新流式发送后，UI 提示 `AI 流式连接中断，请检查网络后重试`。
- 证据：
  - `testing/.artifacts/android-agent-stream-error.png`
  - `testing/.artifacts/android-chat-history-summary.txt`
- 关联台账：
  - `testing/安卓/功能测试/functional_feature_matrix.csv`
  - `testing/安卓/测试分类总台账.csv`
- 当前结论：Blocked / 失败，不得记为通过。
- 解除条件：
  - 明确 `Socket closed` 的根因并修复客户端 SSE 处理、代理转发或后端流式输出中的一处真实问题。
  - 修复后需再次真机复测并留存截图与 logcat。

## 2. Android 草稿列表 UI 无可达入口

- 现象：`DraftListScreen` 路由已注册，但当前真机 UI 里没有可见入口，无法从工作台进入草稿列表。
- 证据：
  - `testing/.artifacts/2026-07-05-android-draft-route.txt`
  - `testing/.artifacts/zhihuiji-ui-assistant3.xml`
- 关联台账：
  - `testing/安卓/功能测试/functional_feature_matrix.csv`
  - `testing/安卓/测试分类总台账.csv`
- 当前结论：Blocked / 部分完成。
- 解除条件：
  - 增加可达入口，或补一个受支持的启动方式直达 `draft_list`。
  - 入口补齐后需重新验证草稿列表、确认、取消闭环。

## 3. Android Agent 审计/轨迹入口未见可达路径

- 现象：真机会话列表抽屉和历史会话详情都已能打开，但当前 UI 中未观察到审计/轨迹入口，暂时无法把 Android 侧 audit 真机链路补齐到通过。
- 证据：
  - `testing/.artifacts/android-conversation-delete-before-summary.txt`
  - `testing/.artifacts/android-conversation-delete-after-summary.txt`
  - `testing/.artifacts/android-agent-audit-no-entry-summary.txt`
  - 当前真机 `uiautomator` dump 仅能看到会话列表、消息卡和删除会话按钮，未见审计/轨迹相关入口
- 关联台账：
  - `testing/安卓/功能测试/functional_feature_matrix.csv`
  - `testing/安卓/测试分类总台账.csv`
- 当前结论：Blocked / 未完成。
- 解除条件：
  - 在现有 UI 上提供可见的审计/轨迹入口，或提供稳定的直达路由/深链。
  - 入口可达后，重新跑历史会话审计验证并回填台账。

## 4. Android ADB 中文输入限制

- 现象：`adb shell input text` 直接输入中文时，出现 `NullPointerException`。
- 证据：
  - `testing/.artifacts/android-chinese-input-test-summary.txt`
- 影响：只能通过已有历史、脚本或其他输入方式完成中文场景验证。
- 解除条件：
  - 改用支持中文输入的注入方式，或通过自动化脚本/剪贴板方案完成输入。

## 5. 草稿确认的最小夹具要求

- 现象：`create_sale_order` 草稿确认时，如果 `items` 为空，会直接失败并提示 `订单明细不能为空`。
- 证据：
  - `testing/.artifacts/backend-draft-confirm-cancel-summary.txt`
  - `testing/.artifacts/backend-draft-confirm-success-summary.txt`
- 影响：测试必须先准备最小商品夹具，再做 confirm。
- 解除条件：
  - 这不是产品缺陷，不需要修复；只需在测试执行时遵守最小夹具策略。

## 6. Android 文本生图提交后未见生成态或结果回写

- 现象：真机 `Agent` 页面可打开“文本生图”弹层，提示词输入框可编辑，`开始生成` 也可点亮；但点击提交后，界面未进入可见生成态，也未看到结果页或明确失败提示，最后回到聊天页。
- 证据：
  - `testing/.artifacts/ui_modal_filled.xml`
  - `testing/.artifacts/shot_modal_filled.png`
  - `testing/.artifacts/ui_after_text_generate_submit.xml`
  - `testing/.artifacts/shot_after_text_generate_submit.png`
- 关联台账：
  - `testing/安卓/功能测试/functional_feature_matrix.csv`
  - `testing/Agent/功能测试/functional_feature_matrix.csv`
- 当前结论：Blocked / 未闭环，不得记为“完整通过”。
- 解除条件：
  - 明确按钮提交后的实际网络请求与回写逻辑，修复客户端状态切换或后端返回路径中的真实问题。
  - 修复后需重新提交文本生图并留存生成态、结果页或错误提示的真机证据。
