# UI 设计规范

本文档根据 [design-mockups](/Users/sunyiyang/Desktop/Project/master-goods/docs/design-mockups) 中 `01.png` 到 `08.png` 反推。最终 Android Compose 实现要以这些设计板为视觉目标，而不是只满足功能可用。

## 设计目标

- 风格关键词：简洁、高效、美观、毛玻璃、轻量经营工具。
- 信息密度：偏高，但通过卡片分组、状态色、数字层级保持可扫读。
- 页面气质：经营管理 App，不做营销式大图页面；首屏直接给业务操作和数据。
- 视觉一致性：所有页面都使用同一套浅蓝背景、玻璃卡片、蓝色主按钮、五栏底部导航。

## 全局视觉规则

- 背景：全屏浅蓝到近白的柔和渐变，顶部更冷、更亮，底部接近白色。
- 毛玻璃卡片：半透明白色卡片，轻描边，弱阴影；卡片内用细分割线组织信息。
- 圆角：页面主卡片 12dp 到 16dp，输入框和筛选胶囊 10dp 到 12dp，底部大按钮 12dp。
- 间距：屏幕水平边距 16dp，卡片内边距 12dp 到 16dp，列表项垂直间距 8dp 到 10dp。
- 顶栏：保留系统状态栏下方 44dp 到 52dp 内容高度；标题左侧大标题或居中标题按页面类型选择。
- 底栏：五个固定入口：首页、单据、档案、报表、助手；激活态使用蓝色图标与文字。
- 浮动按钮：新增、调整库存、新建付款单等高频操作使用右下蓝色悬浮胶囊按钮。
- 底部操作区：详情页和编辑页底部放固定操作按钮，主操作为蓝色实心，次操作为白色描边。

## 颜色规范

- 主色：`#1677FF` 或接近 Android Material blue，用于主按钮、激活 Tab、链接、关键金额。
- 主色渐变：按钮可使用从 `#2F8CFF` 到 `#0F73F6` 的轻微纵向渐变。
- 成功：`#18B66A`，用于已完成、正常、收入、增长。
- 警告：`#FF9F1A`，用于低库存、部分入库、排队中。
- 危险：`#F04438`，用于欠款、失败、作废、退款或风险提醒。
- 信息蓝：`#3B82F6`，用于待收款、进行中、报表曲线。
- 中性文字：主文本接近 `#111827`，次文本 `#64748B`，弱文本 `#94A3B8`。
- 边框与分割线：使用浅蓝灰，接近 `#D8E6F5`，透明度要低。

## 字体与数字层级

- 字体：优先使用系统中文无衬线，保持 Android 原生可读性。
- 页面大标题：24sp 到 28sp，粗体。
- 页面标题：18sp 到 20sp，半粗体。
- 卡片标题：14sp 到 16sp，半粗体。
- 正文：13sp 到 14sp。
- 辅助信息：11sp 到 12sp。
- 核心金额：22sp 到 30sp，使用粗体；金额符号可小一号。
- 表格数字：右对齐，金额和数量要形成纵向对齐。

## 组件规范

- `ZhihuijiTheme`
  - 统一颜色、字体、形状、阴影、状态栏颜色和导航栏颜色。
- `GlassScaffold`
  - 提供渐变背景、状态栏适配、底部导航占位、内容安全区。
- `GlassTopBar`
  - 支持大标题、居中标题、返回、搜索、筛选、更多、打印、扫码等动作。
- `GlassCard`
  - 所有信息分组默认使用这个卡片。
- `KpiCard`
  - 首页和报表的关键指标卡，包含图标、标题、主数字、同比或说明。
- `StatusPill`
  - 状态标签，支持正常、低库存、缺货、待收款、已完成、作废、部分入库、待付款、进行中、失败。
- `SearchFilterBar`
  - 搜索框加筛选按钮，列表页通用。
- `SegmentedTabs`
  - 顶部分类切换，文案必须绑定当前业务真实状态；例如销售列表使用全部、草稿、已完成、已取消、已确认，不能用不存在的“待发货”等旧口径占位。
- `FilterChipRow`
  - 横向胶囊筛选，例如商品分类、时间筛选、客户筛选。
- `QuantityStepper`
  - 销售开单和采购开单中的减号、数量、加号控件。
- `BottomActionBar`
  - 编辑页、详情页、付款页底部操作按钮容器。
- `EmptyState`
  - 收款记录为空、任务为空等页面使用轻插画或浅蓝图标，不使用大段说明文字。
- `ChartCard`
  - 趋势图、环形图、排行榜卡片统一外观。

## 导航规范

- 首页：经营看板、待处理提醒、低库存、应收跟进。
- 单据：销售单、采购单、付款单、资金流水。
- 档案：商品、客户、供应商。
- 报表：总览、库存流水、对账汇总。
- 助手：AI 工作台、AI 问答、操作草稿、任务与通知。

底部导航图标要与设计图一致地保持线性风格，当前页使用蓝色实心或加粗效果，非当前页使用灰蓝色。

## 页面模式

- 列表页：顶部标题 + 搜索栏 + 状态 Tab + 可选筛选 Chip + 玻璃列表卡片 + 右下新增按钮。
- 详情页：顶部返回 + 主信息卡 + 汇总卡 + 明细卡 + 历史记录 + 底部操作区。
- 编辑页：顶部返回 + 表单分组卡 + 明细表格卡 + 金额汇总卡 + 备注卡 + 底部提交操作。
- 报表页：日期范围选择 + 四宫格 KPI + Tab + 图表或表格卡片。
- AI 页：机器人头像和欢迎语 + KPI 卡 + 洞察卡 + 快捷操作 + 聊天输入或任务列表。
- 设置页：分组列表卡 + 同步状态 + 缓存信息 + 红色描边退出登录按钮。

## 新增业务落位规则

- 新增业务不等于新增风格。
- 后续商品扩域、单据扩域、财务/库存扩域、同步/导入扩域，都必须优先落入上述既有页面模式，而不是重新发明新的页面结构。
- 允许扩展的是：
  - 卡片块数量
  - 状态标签种类
  - 明细行字段
  - 底部操作区组合
  - 图表/指标内容
- 不允许漂移的是：
  - 全局背景和色系
  - 顶栏和底栏结构
  - 主次按钮层级
  - 卡片圆角、描边、间距体系
  - 状态色语义
- 如果某个新业务看起来“放不进去”，优先说明是页面职责拆分问题，而不是先改视觉语言。

## 图标与状态

- 高价值操作必须有图标：新增、搜索、筛选、扫码、打印、通知、同步、收款、付款。
- 状态标签不要只靠文字，需要同时使用颜色区分。
- 风险类状态使用暖色，但面积要小，避免整页变成警告色。
- 金额正负要颜色化：收入和增长绿色，欠款和支出红色，主合计蓝色。

## 实现验收

- 任意页面截图应能明显看出浅蓝毛玻璃风格。
- 所有 feature 页面必须使用 `GlassScaffold`、`GlassTopBar`、`GlassCard`、`StatusPill`、`BottomActionBar` 中的适用组件。
- 列表页必须包含搜索、筛选或状态切换中的至少一种。
- 录单页必须有底部固定主操作按钮，避免提交入口随滚动丢失。
- 关键数字、状态、操作按钮的颜色必须与本文规范一致。
- 大范围新增业务后，截图仍应被识别为同一产品，而不是“旧页面一套风格、新页面另一套风格”。
